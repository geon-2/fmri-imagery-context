# 교수님용 쉬운 설명 (비전공자 기준)

원칙: **전문용어를 먼저 말하지 않는다.** 쉬운 말로 먼저 말하고, 용어는 괄호로 한 번만 붙인다. 숫자는 한 장에 하나만.
이 문서의 설명은 이해를 돕는 비유이고, 정확한 정의는 `script_1008_easy.md`의 용어표를 따른다.

---

## 0. 한 문장 / 세 문장

**한 문장:** 뇌 스캔으로 "머릿속에 떠올린 장면"을 읽고 싶은데, 신호가 너무 약해서 장면을 통째로 맞히는 대신 **장면의 큰 특징 12가지만 맞히는 방식**이 더 잘 되는지 확인하는 연구입니다.

**세 문장:**
1. 사람이 실제로 본 장면은 뇌 스캔(fMRI)으로 어느 정도 읽히지만, 떠올린 장면은 잘 안 읽힙니다. 신호가 훨씬 약하기 때문입니다.
2. 그래서 장면을 세세하게 전부 맞히려 하지 않고, **"실내냐 야외냐, 스포츠냐 음식이냐"처럼 큰 특징 12개만** 맞히도록 바꿔 봅니다.
3. 12개를 아무렇게나 고르지 않고 **실제 뇌가 반응하는 특징 기준으로 고릅니다.** 지금까지는 "본 장면"에서 이게 되는지 확인했고, "떠올린 장면"은 아직 시험하지 않았습니다.

---

## 1. 비유: 사진을 12개 점수로 설명하기

사진 한 장을 설명한다고 해 봅시다. "스키장 아래쪽에서 사람 둘이 눈사람 뒤에 서 있다"처럼 쓸 수도 있지만, **12개 점수**로 요약할 수도 있습니다. 예를 들어 이런 식입니다.

| 질문 | 이 사진의 점수 |
|---|---|
| 얼마나 야외인가 | 높음 |
| 얼마나 스포츠 느낌인가 | 높음 |
| 얼마나 음식 느낌인가 | 낮음 |
| … (12개까지) | … |

모든 사진을 이 12개 점수로 나타내면, 사진 한 장 = 숫자 12개가 됩니다. 이것이 "저차원"입니다. 원래 컴퓨터는 사진 설명을 **숫자 768개**로 나타내는데, 그걸 12개로 줄인 것입니다.

(주의: 점수 하나가 정확히 하나의 의미라는 보장은 없습니다. "이런 느낌의 질문들"이라는 비유일 뿐입니다. 이 점은 제가 가정으로 두고 있고 확인이 필요하다고 말씀드립니다.)

용어 연결: 질문 하나 = **축(방향, latent dimension)**, 12개 묶음 = **12차원 부분공간**, 768개 → 12개 = **차원 축소**.

---

## 2. 전체 과정을 한 줄로 (파이프라인)

```
사진 → 글로 설명(라벨) → 숫자 768개 → 그중 "뇌와 관련된 12개 점수"만 고름
                                              ↓
              뇌 스캔 → (컴퓨터가 학습) → 이 12개 점수를 맞힌다
                                              ↓
                          떠올린 장면의 뇌 스캔에도 똑같이 적용  ← 아직 안 함
```

세 단계로 말하면 됩니다.

1. **12개 점수를 정한다.** 사진 설명 글로, 뇌 반응을 가장 잘 설명하는 12개 질문을 고릅니다. (사진 하나당 점수 12개가 정답이 됩니다.)
2. **뇌 스캔으로 그 점수를 맞히게 학습시킨다.** 본 장면의 뇌 스캔을 컴퓨터에 보여 주고, "이 사진의 12개 점수는 얼마?"를 맞히게 합니다.
3. **떠올린 장면에 적용한다.** 같은 컴퓨터에 떠올린 장면의 뇌 스캔을 넣어 봅니다. 이것이 최종 목표이고 **아직 하지 않았습니다.**

가장 헷갈리는 점 하나: **1단계와 2단계는 서로 다른 일입니다.** 1단계는 "무엇을 맞힐지 정하는 일", 2단계는 "그걸 뇌에서 맞히는 일"입니다.

---

## 3. 이번에 확인한 것: 4가지를 쉬운 말로

슬라이드 한 장당 "무엇을 알고 싶었나 → 어떻게 확인했나 → 결과 한 줄 → 부족한 점 한 줄"로만 말합니다.

**① 라벨(사진 설명)이 믿을 만한가**
- 알고 싶은 것: AI가 붙인 설명이 사진과 맞는가.
- 확인: 무작위 80장을 제가 직접 봤고, 같은 사진에 두 번 독립적으로 설명을 붙여서 비슷한지 봤습니다.
- 결과: 틀린 설명은 0~0.4%. 두 번 붙인 설명으로 같은 사진을 찾으면 97%.
- 부족한 점: 확인한 사람이 한 명이고, 두 번째도 같은 AI입니다.

**② 맥락 설명이 사물 이름보다 뇌를 더 잘 설명하는가**
- 알고 싶은 것: "사람, 스키" 같은 사물 이름만 알 때보다, 장소·분위기 같은 맥락을 알 때 뇌 반응을 더 잘 맞히는가.
- 확인: 글만 바꿔서 뇌 반응을 예측해 비교. 맥락 설명을 다른 사진 것으로 섞어 넣은 경우도 비교.
- 결과: 맥락 0.439, 사물 이름 0.380. 섞으면 0.004로 떨어집니다(진짜 내용에서 나온 점수라는 증거).
- 부족한 점: 사물 이름은 사진당 평균 2.8개뿐이라 약한 비교입니다.
- 점수 읽는 법: 이 점수는 0~1이고, 뇌 신호에 잡음이 많아서 이론상 최대가 약 0.63입니다. 그래서 0.44는 낮은 게 아니라 최대치의 약 70%입니다.

**③ 12개만으로 충분한가, 사람이 달라도 같은가**
- 알고 싶은 것: 768개 중 12개만 써도 뇌 예측이 유지되는가. 다른 사람에게도 통하는가.
- 결과: 뇌 기준으로 고른 12개는 768개 전체와 같은 수준(0.430 대 0.432). 뇌를 보지 않고 고른 12개는 0.373. 다른 피험자의 12개를 가져와도 거의 같음(0.426).
- 쉬운 해석: 뇌와 관련된 정보는 12개 정도로 요약되고, 이 요약은 사람마다 비슷합니다.
- 부족한 점: 한 방향씩의 의미가 아니라 12개 묶음 단위로만 말할 수 있습니다.

**④ 뇌 스캔에서 그 12개 점수를 맞힐 수 있는가**
- 알고 싶은 것: 컴퓨터가 뇌 스캔만 보고 사진의 12개 점수를 맞히는가.
- 확인: 학습에 안 쓴 사진 1,000장 중에서 뇌 스캔으로 정답 사진을 찾게 했습니다(찍으면 0.1%).
- 결과: 9~14%. 찍는 것의 약 100배이지만 정확하지는 않습니다.
- 부족한 점: 처음 세운 평가 기준은 너무 쉬워서(98% 이상) 차이를 가릴 수 없었고, 1,000장 중 찾기는 결과를 본 뒤에 추가한 지표입니다.

## 4. 솔직하게 정리: 말할 수 있는 것 / 없는 것

**말할 수 있다**
- 맥락 설명이 사물 이름보다 뇌 반응을 더 잘 설명한다.
- 12개 점수만으로도 전체와 비슷하게 뇌를 설명하고, 사람이 달라도 비슷하다.
- 뇌 스캔에서 그 점수를 읽을 수 있다(정확도는 낮음).

**아직 말할 수 없다**
- 이 12개가 "사물과 무관한 맥락"만 담았다. (상위 방향의 59%는 사물 종류로 설명됩니다.)
- 뇌가 실제로 12개로 압축해서 저장한다. (신호가 약해서 그렇게 보일 수도 있습니다.)
- **떠올린 장면에서도 통한다. (아직 시험하지 않았습니다.)**

## 6. 발표 순서 제안 (이해 못 하시는 지점을 먼저 풀기)

기존 순서는 방법 → 결과인데, 이번에는 **"왜 이걸 하는가 → 비유 → 파이프라인 → 결과"** 순으로 가는 것을 권합니다.

| 순서 | 내용 | 시간 |
|---|---|---|
| 1 | 한 문장 + 세 문장 (0절) | 1분 |
| 2 | 사진을 12개 점수로 설명하는 비유 (1절) | 2분 |
| 3 | 파이프라인 그림 한 장, "아직 한 것 / 안 한 것" 표시 (2절) | 2분 |
| 4 | 결과 ①~④, 장당 1분 (3절) | 5분 |
| 5 | 말할 수 있는 것 / 없는 것 (4절) | 1분 |
| 6 | 다음 계획과 질문 (5절) | 2분 |

이 순서에서 **ROI별 분석, 사물 제거 분석, 라벨 항목별 세부**는 본문에서 빼고 질문이 나올 때만 씁니다. 처음 듣는 분께는 정보량이 너무 많습니다.
