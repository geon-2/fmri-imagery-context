# 발표 구조안 v2 (리마인드 → 이전 요약 → 이번 주 두괄식)

구조만 확정하는 문서입니다. 이 구조가 승인되면 대본과 슬라이드 문구를 쓰고, 마지막에 윤문합니다.

## 전체 흐름

| 파트 | 목적 | 말하는 방식 | 분량 |
|---|---|---|---|
| A. 프로젝트 리마인드 | 어떤 프로젝트인지 다시 상기 | 문제 → 아이디어 → 파이프라인 → 연구 질문 | 약 5장 |
| B. 이전까지 한 일 | 지난 미팅 이후 맥락 연결 | 간단 요약 (세부 설명 없음) | 1~2장 |
| C. 이번 주 한 일 | 이번 미팅의 본론 | **두괄식**: 결론 먼저 → 단계별 세부 | 약 8장 |
| D. 정리와 다음 | 피드백 받기 | 말할 수 있는 것 / 없는 것, 다음 계획, 질문 | 약 2장 |

두괄식은 C 파트에만 적용합니다. A와 B는 순서대로 이야기하는 방식입니다.

## 용어 고정 (처음 한 번 정의하고 끝까지 같은 말)

| 쓸 말 | 뜻 |
|---|---|
| 임베딩 | 문장을 768차원 벡터로 바꾼 것 |
| 타깃(target) | 디코더가 맞혀야 하는 값 |
| 차원 축소 | 768차원 임베딩을 k=12차원으로 줄이는 것 (k는 하이퍼파라미터) |
| 잠재 차원 | 차원 축소 후의 12개 좌표 하나하나 (기존 "축") |
| 인코딩 모델 | 임베딩 → 뇌 반응(복셀) 예측 |
| 디코더 | 뇌 반응(복셀) → 타깃 예측 |
| RRR | 뇌 반응을 가장 잘 설명하는 k차원 부분공간을 고르는 방법 (기존 "뇌에 맞춘 축") |
| PCA 베이스라인 | 뇌를 보지 않고 임베딩 분산 기준으로 k차원을 고르는 방법 |
| 홀드아웃 | 학습에 쓰지 않은 평가용 이미지(shared1000) |
| 노이즈 상한 | 잡음 때문에 어떤 모델도 넘을 수 없는 점수 (인코딩 약 0.63) |
| top-1 검색 정확도 | 홀드아웃 1,000장 중 정답 이미지를 1등으로 찾은 비율 (우연 0.1%) |

"축"이라는 말은 쓰지 않습니다. 필요하면 "잠재 차원" 또는 "k차원 부분공간"이라고 합니다.

## A. 프로젝트 리마인드

### 1. 표지
제목, 진행 상황 보고, 날짜.

### 2. 문제
- 핵심 한 줄: 본 장면을 잘 푸는 모델이 떠올린 장면을 잘 푸는 것은 아니다.
- 시각화: 막대 그래프(Brain Diffuser 73.95, MindEye1 73.00, MindEye2 56.96, 우연 50)

### 3. 아이디어
- 핵심 한 줄: 신호가 약하면 타깃을 작게 한다. 768차원 → 12차원.
- 시각화: 768개 점이 12개로 줄어드는 그림.
- 저차원이 유리하다는 것은 이미 알려져 있다. 우리가 묻는 것은 **같은 12차원이라면 뇌를 보고 고른 것이 PCA보다 나은가**이다.

### 4. 파이프라인 (전체 그림, 이후 모든 장의 지도)
```
이미지 → 라벨 → 텍스트 → 임베딩(768)
                          │ ① RRR로 12차원 선택 (인코딩, perception fMRI)
                          ▼
                    12차원 타깃
                          ▲ ② 디코더: 복셀 → 12차원 (perception fMRI로 학습)
                          │
                    ③ imagery fMRI에 그대로 적용 (미착수)
```
- 시각화: 위 그림. 단계마다 완료 / 진행 중 / 미착수 색상.

### 5. 연구 질문
- RQ1(사전 확인) / RQ2(주 가설) / RQ3(추가 실험). 이번 주 범위는 RQ1에 음영.
- 시각화: 표 3줄.

---

## B. 이전까지 한 일 (간단 요약)

### 6. 이전까지 한 일
- 핵심 한 줄: 12차원을 만들 재료(라벨, 데이터)는 준비했고, 분석은 이번 주에 시작했다.
- 내용(4줄 이내):
  - 이미지 맥락 라벨 6개 항목, 20,877장 (AI 라벨링)
  - 평가용 shared1000은 학습에서 제외
  - 텍스트 3종(원본 캡션 / 사물 이름 / 맥락 라벨)을 같은 임베딩 모델로 변환
  - 피험자 4명의 fMRI 준비
- 시각화: 파이프라인 그림에서 "재료 준비" 구간만 강조한 타임라인 한 줄.

---

## C. 이번 주 한 일 (두괄식)

### 7. 이번 주 결론 (먼저 말하는 장) ← 가장 중요한 장
- 확인한 것 4가지, 장마다 숫자 하나:
  1. 라벨은 믿을 만하다 (오류 0~0.4%)
  2. 맥락이 사물 이름보다 뇌를 더 설명한다 (0.439 대 0.380)
  3. 12차원이 768차원 전체와 같다 (0.430 대 0.432), 피험자 간에도 공유된다
  4. 뇌에서 12차원 타깃을 읽을 수 있다 (top-1 9~14%, 우연 0.1%)
- 아직 안 한 것: **imagery에 적용**
- 시각화: 파이프라인 위에 ①~④를 표시한 한 장. 한 장만 봐도 이번 주가 전달되도록 한다.

### 8. 단계 0: 라벨이 믿을 만한가
- 결과: 직접 확인 오류 0~0.4%, 재라벨링 후 동일 이미지 검색 97%
- 시각화: 막대 2개(왼쪽 오류율, 오른쪽 일관성)

### 9. 단계 ①-a: 맥락이 사물 이름보다 뇌를 더 설명하는가
- 결과: 맥락 0.439 > 사물 이름 0.380, 셔플 대조 0.004
- 시각화: 막대 그래프 + 노이즈 상한 점선(0.63)

### 10. 단계 ①-b: 12차원이면 충분한가, 피험자가 달라도 같은가
- 결과: RRR 12차원 0.430 ≈ 768차원 0.432, PCA 12차원 0.373. 부분공간 겹침 피험자 간 0.39 / 같은 사람 반분할 0.42 / 무작위 0.016
- 시각화: k 대 점수 곡선(RRR / PCA / 무작위 / 전체) + 겹침 막대 3개

### 11. 단계 ②: 뇌에서 12차원 타깃을 읽을 수 있는가
- 결과: top-1 9~14%(우연 0.1%), 같은 범주 안 22~27%, 범주 제외 5~7%
- 한계(꼭 말하기): 사전 기준 지표는 천장 효과로 미충족, top-1은 사후 추가
- 시각화: 4단계 난이도 막대

### 12. 확인: 사물 정보 때문은 아닌가
- 결과: 12차원의 59%는 COCO 사물 범주로 설명됨, 선형으로 제거한 뒤에도 0.24~0.28 남음
- "독립이라고는 말하지 않는다"를 명시.
- 시각화: 제거 전후 막대.

### 단계 슬라이드 형식 (8~12번 공통)

상단에 파이프라인 위치 표시를 작게 붙이고, 아래 5줄만 씁니다.

1. **질문:** 무엇을 알고 싶었나
2. **가정:** 왜 이렇게 될 거라고 봤나 (사고 흐름은 여기서만 짧게)
3. **시도:** 무엇을 어떻게 했나
4. **결과:** 숫자 하나 + 그림 하나
5. **한계:** 한 줄

## D. 정리와 다음

### 13. 말할 수 있는 것 / 없는 것
- 2열 표. 없는 것에는 **imagery에서 통한다**를 맨 위에.

### 14. 다음 계획 + 질문 3개
- 다음: imagery에 디코더 적용 → 읽히면 타깃별 비교(기준은 데이터 열기 전에 기록)
- 질문: ① 맥락을 사물 이름 이상으로 정의하면 충분한가 ② imagery 자연 장면 5장으로 충분한가 ③ ROI별 분석을 어디에 넣을까
