# 라벨 교차 검증 세 가지: 판정 기준 (실행 전에 기록, 2026-10-10)

배경: 36,977장 요약 통계·검증에서 V1(최소 개수)·V4(버전 차이)가 v9 코어 1,000장 때문에 미통과했고(`docs/label_validation_criteria_scale.md`, `results/tables/label_summary_full.md`), 같은 이미지에서 라벨이 얼마나 일관되는지를 더 큰 표본으로 확인하기로 했다.
지표는 기존 재현성 검사(`src/labeling/repro_check.py`, 10/7 기록)와 같다: 한 쪽 라벨 텍스트(TF-IDF 코사인)로 다른 쪽에서 같은 이미지를 찾는 식별 정확도(top-1, top-5), 차원별 식별(notes 제외), 같은 이미지 쌍 대 다른 이미지 쌍의 평균 코사인. 같은 모델·프롬프트의 일관성이지 타당성이 아니다.
식별 정확도는 후보 수에 따라 달라지므로, 항상 후보 300장 규모의 무작위 블록(seed 고정)으로 나눠 계산하고 블록 평균과 표준편차를 보고한다. 이번 결과를 보고 기준을 바꾸지 않는다.

기준 숫자는 제안(사용자 확인 전)이다. 기존 300장 결과(pass 0 대 pass 9, 후보 300장): 전체 top-1 0.973, 장소 유형 0.763, 환경 0.690, 활동 0.740, 암묵적 사건 0.577, 공간 규모 0.393.

## R1. 코어 1,000장 v10 재라벨링 (pass 1)
- 대상: 큐 앞 1,000장(v9 코어). 같은 프롬프트(v10), 같은 모델(gpt-5.5 medium), 독립 세션. 이미 pass 1이 있는 앞 100장은 건너뛴다.
- 구조: 1,000장 모두 검증기를 통과해 pass 1에 저장(최소 개수 100% 충족).
- 일관성: pass 0(v9) 대 pass 1(v10) 식별 정확도 전체 top-1 ≥ 0.50(기존 기준), 차원별은 보고. v9가 더 짧은 라벨이므로 차원별 수치가 위 기존값보다 낮을 수 있다는 점을 명시.
- 보고: v9 대 v10의 이미지당 라벨 수·구 단어 수 차이(V4의 확인).

## R2. 무작위 2,000장 재현성 (pass 2)
- 대상: v10 이미지(코어 제외) 중 무작위 2,000장(seed 20261010). 같은 프롬프트·모델의 독립 두 번째 샘플.
- 구조: 모든 이미지가 검증기를 통과해 저장(최소 개수 100%).
- 일관성: pass 0 대 pass 2의 300장 블록 평균 전체 top-1 ≥ 0.50. 차원별 top-1이 기존 300장 결과와 각각 ±0.10 이내(환경 0.69, 활동 0.74, 암묵적 사건 0.58 등). 벗어나면 「기존 300장 수치가 표본 변동이었다」고 보고하고 해석을 고친다.
- 보고: 차원별 Jaccard, 같은 쌍 대 다른 쌍 코사인.

## R3. 다른 모델 교차 검증 (Claude, R2 표본의 앞 200장)
- 대상: R2의 무작위 2,000장 중 앞 200장. Claude(Sonnet)가 같은 프롬프트(context-classify, v10)로 독립 라벨링. 이미지를 직접 보고 만든다.
- 일관성: pass 0(Codex) 대 Claude의 식별 정확도 전체 top-1 ≥ 0.50(후보 200장, 우연 0.5%). 차원별은 보고. 모델이 달라 같은 모델 재현성(R2)보다 낮을 것으로 예상하며, R2와의 차이를 「모델 차이 대 표본 차이」로 나눠 보고한다.
- 3자 비교: 같은 200장에서 pass 0, pass 2, Claude의 세 쌍 일관성을 같이 보고한다.
- 구조: Claude 출력은 검증기(`validate_unit.py`)와 같은 규칙으로 검사해 최소 개수 충족률을 보고한다(기준은 설정하지 않음, 모델 비교용).
- 이 단계는 타당성(이미지에 맞는가)을 직접 보증하지 않는다. 일치하지 않은 부분을 표본으로 확인하는 것은 사용자 판정(V7)로 남긴다.

## 하지 않는 것
- 라벨 값의 의미적 정확도 판정(V7, 사용자·다른 세션).
- 결과에 따른 라벨 삭제. 항상 보존하고 표시만 한다.
