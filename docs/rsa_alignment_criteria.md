# RSA·부분공간 정렬 시험(ROI별) — 판정 기준 (실행 전에 기록, 2026-10-15)

배경: 병목 점검 1·2(`docs/bottleneck_feasibility_criteria.md`)는 세트 A·C에서 imagery 신호가 약해 「검증 불가」였다. 복셀 패턴을 직접 사영하는 대신 조건 간 거리 구조(RDM)를 쓰면 시행 노이즈에 덜 민감할 수 있어 같은 질문을 다시 본다. 문헌 근거와 교차 검증은 `docs/literature_crosscheck_1015.md`, 논의는 `docs/discussion_1015_new_directions.md`. 숫자 기준은 제안이며 결과를 본 뒤 바꾸지 않는다. 탐색 단계. 지각 → imagery 일반화에 대한 시험이며 복원 성능 시험이 아니다.

## 먼저 정리할 선결 조건 (실행 전 사용자 확인)
1. **세트 B(자연 장면) 사용 방식(2026-10-15 결정, Notion 「새 논의 정리」 페이지에 기록됨).** 「한 번만 연다」는 약속은 없앴다. 대신 **피험자 또는 자극을 나눠 한쪽은 확인용(held-out)으로 남긴다.** 탐색용 쪽 결과는 「탐색 결과」로 표시하고, 확인용 쪽은 판정 기준을 먼저 적은 뒤에만 연다. **구체적 분할(피험자 대 자극, 어느 쪽이 탐색·확인인지)은 아직 미정이며 결과를 보기 전에 정해 Notion에 기록한다.** 그 전에는 **세트 A·C만 실행**하고 세트 B 반응은 읽지 않는다.
2. **세트 B 자극의 맥락 라벨.** 세트 B의 complex 6개 중 5개는 NSD shared1000(+ 미술작품 1개)이다. 라벨링 파일럿과 축 학습에서 shared1000을 제외한다는 규칙과 별개로, 이 6개에 맥락 라벨을 붙이는 것은 평가용 타깃을 만드는 일이다. 같은 라벨링 절차를 쓰되 학습·축 추출에 쓰지 않는다는 조건으로 사용자가 허용해야 한다. 허용 전에는 T2(텍스트 타깃 RSA)를 세트 B에서 하지 않는다.
3. 세트 C(단어 cue)는 텍스트 자체가 있어 T2의 양성 대조로 쓸 수 있다. 세트 A(도형)는 텍스트 타깃이 없으므로 모양 모델 RDM(조건 간 방향·형태 차이)으로 파이프라인 양성 대조만 한다.

## 데이터와 고정
- 피험자 1·2·5·7(40세션 완료, 지각 학습 가능). NSD-Imagery vision 8회, imagery 16회(imagery run 2개). GLM b3, run별 z-score는 NSD-Imagery 공개 전처리를 그대로 쓰고 별도 처리를 추가하지 않는다. 첫 imagery run 포함/제외를 둘 다 계산하고 **주 결과는 포함**(벤치마크와 같게)이다. 제외는 민감도.
- 복셀: 전처리 a(세션 z-score + 반복 신뢰도 ≥ 0.1, 피험자별). 복셀 선택과 부분공간·축 학습은 NSD 지각 데이터에서만 한다. imagery 데이터로 복셀·차원·ROI·정규화 값을 고르지 않는다.
- ROI: EARLY, S_ventral, S_lateral, S_parietal(NSD streams), floc 세부(faces, places, bodies, words), ALL. 복셀 수를 맞추기 위해 모든 ROI에서 a로 고른 복셀 중 **500개 무작위(시드 3회)** 로 반복(E5와 같은 방식). 500개 미만인 ROI는 그 피험자에서 제외하고 기록한다. 전체 복셀 결과는 참고로 함께 낸다.
- 평가 단위: 피험자 4명 × 세트(현재 A·C) = 8단위.

## T0. 신뢰도 선결(ROI별)
- imagery run 1 대 run 2 RDM의 상관(split-half). 조건 라벨 정확 순열(6! = 720)로 p를 낸다.
- 「ROI가 검증 가능」: 8단위 중 6개 이상에서 순열 p < 0.05. 아니면 그 ROI는 「imagery 신호가 약해 검증 불가」로 쓰고 아래 T1~T4를 해석하지 않는다(숫자는 보고).
- **vision RDM 신뢰도도 같은 방식으로 보고**한다(양성 대조). vision이 안 되면 파이프라인 문제로 본다.

## T1. 지각-imagery RDM 정렬(ROI별)
- 거리: crossnobis(교차검증 Mahalanobis). imagery는 run 단위 2폴드, vision은 반복을 홀짝 반으로 나눈 2폴드. 공분산은 잔차의 수축 추정(학습 폴드에서만).
- 지표: vision RDM과 imagery RDM의 Spearman 상관 r_VI. 노이즈 천장: vision split-half와 imagery split-half의 기하평균 상한 r_ceil. 보정값 r_VI / r_ceil은 T0 통과 ROI에서만 해석한다. 보정 전 값도 함께 낸다.
- 우연 분포: 조건 라벨 정확 순열 720개.
- 판정(ROI별): 「정렬 있음」 = 8단위 중 6개 이상에서 r_VI가 순열 95백분위 초과 + 평균 r_VI/r_ceil ≥ 0.3. 「정렬 없음」 = T0 통과 + 정렬 있음 조건 실패인 단위가 5개 이상. 그 외 「판단 불가」.

## T2. 텍스트 타깃 압축과 RSA (선결 2 충족 후, 세트 C부터)
- 모델 RDM: 세트 C의 단어 cue(및 선결 2 허용 시 세트 B의 맥락 라벨)를 CLIP ViT-L/14 텍스트로 임베딩한 뒤 k차원(k = 4, 8, 12; 주 k = 8, 결과 전 고정)으로 압축해 조건 간 거리 RDM을 만든다.
- 압축 방법(모두 학습은 NSD 지각 데이터와 NSD 라벨에서만, 세트 C·B 자극은 학습에 쓰지 않음): (a) 텍스트 PCA, (b) 뇌 정렬 축(DDR 또는 RRR, B 단계와 같은 방법, ROI별로 따로 학습), (c) 무작위 직교 방향(500회), (d) 압축 없음(전체 차원).
- 지표: 모델 RDM과 imagery RDM의 Spearman 상관, 모델 RDM과 vision RDM의 상관(양성 대조). ROI별로 계산.
- 판정(ROI별): (b)의 imagery 상관이 (a)(같은 k)보다 8단위 중 6개 이상에서 높고 평균 차이 ≥ 0.05이면 「뇌 정렬 축이 imagery에 더 맞음」, 반대면 「PCA가 더 맞음」, 아니면 「차이 없음」. (b)와 (c), (b)와 (d)도 같은 규칙으로 보고. **6개 조건의 RDM(거리 15개)이라 통계 힘이 약하므로 기술 통계와 정확 순열 위주로 쓰고 점근 p값은 쓰지 않는다.**
- 단순·복잡·개념 자극을 하나의 RDM으로 합치지 않는다. 세트별로 따로 낸다.

## T3. 변환 모델 비교(지각 → imagery, ROI별, 탐색)
- 학습: vision 패턴(8회 평균)과 imagery 패턴(16회 평균)의 조건 대응 쌍(세트 안 6개). 평가: 조건 하나 빼기(leave-one-condition-out)로 빠진 조건의 imagery 패턴을 예측(상관).
- 모델 계층: 평균만, 스칼라(약한 vision), 대각(복셀별 이득), 직교 회전(Procrustes), reduced-rank(rank 1~3), 릿지. 하이퍼파라미터는 vision 데이터 안에서만 고른다.
- 6개 조건에서 일반화가 어렵다는 것을 사전에 인정한다. 이 시험은 「약한 vision」(스칼라) 대 「변형된 vision」(회전·rank)의 구분 가능성만 보고, 결과는 기술 통계로만 쓴다. 판정 규칙은 두지 않는다.

## T4. 정렬비 두 방향(ROI별)
- 방향 1(Saha Roy 원문, 시각 분산 기준): a_g = (imagery 부분공간 d_im차원에 사영한 시각 분산) ÷ (시각 부분공간 첫 d_im차원이 설명하는 시각 분산).
- 방향 2(우리 원래 정의, imagery 분산 기준): imagery 패턴이 지각 부분공간 k차원에 사영되는 분산 비율.
- 지각 부분공간은 NSD 지각(학습용 이미지, shared1000 제외)에서만 추정한다. 차원 k는 지각 검증 폴드에서 고른다(imagery로 고르지 않음). k = 12가 주(자극 수 상한과 맞춤), 5·20·32는 민감도.
- null: (i) 같은 k의 무작위 부분공간 500회, (ii) 스펙트럼을 보존한 무작위 회전, (iii) PCA 부분공간(같은 k).
- **노이즈 시뮬레이션:** 지각 부분공간 안에 imagery 평균 패턴이 완전히 들어 있다고 가정하고 관측한 imagery 노이즈 수준을 더한 시뮬레이션을 ROI별 200회 돌려 「완전 재사용일 때의 기대 정렬」을 구한다. 관측 정렬이 이 기대 구간 안이면 「완전 재사용과 구별 안 됨」, 밖이면 「부분 재사용」이다.
- 판정은 무작위 대비(「null 95백분위 초과」, 8단위 중 6개 이상)와 시뮬레이션 대비를 따로 쓴다. 두 방향의 값이 크게 다르면 그 비대칭을 그대로 보고한다.

## 종합 판정
ROI마다 T0~T4의 판정을 표로 낸다. 「이 ROI에서 imagery가 지각 부분공간을 재사용한다」는 말은 T0 통과 + T1 「정렬 있음」 + T4 방향 1과 2 모두 null 초과를 모두 만족할 때만 쓴다. 어느 ROI도 T0를 통과하지 못하면 「이 데이터로는 ROI별 검증 불가」로 끝내고 세트 B·복원으로 넘어가지 않는다. 「EARLY가 다르다」는 말은 EARLY와 고차 ROI의 판정이 4명 중 3명 이상에서 같은 방향으로 갈릴 때만 쓴다.

## 대조·점검
- 셔플 대조: 조건 라벨을 섞은 RDM에서 T1의 r_VI가 0 근처(|r| ≤ 0.1)인지.
- 복셀 수 민감도: ROI별 전체 복셀과 500개 반복, 시드별 변동 보고.
- 전처리 민감도: 첫 imagery run 포함/제외, 복셀 신뢰도 임계값(0.05, 0.1, 0.2).
- 기준선: 지각 안의 split-half(vision) 정렬을 같은 방식으로 내어 imagery 값을 그 위에서 읽는다.

## 한계 (사전)
세트당 조건이 6개라 RDM 쌍이 15개뿐이고 일반화 추론이 매우 약하다. 세트 A·C(도형·단어)의 결과가 자연 장면으로 일반화된다는 보장이 없고, 단어 cue는 장면 맥락 라벨과 다르다. 지각 학습 부분공간이 보지 못한 자극(도형·단어)에서는 정렬이 낮게 나올 수 있다. 피험자 4명. 고차 ROI는 복셀 500개 제한으로 정보가 줄 수 있다. 정렬이 높은 것이 맥락 정보의 재사용을 뜻하지 않는다(단순 대 복잡 같은 거친 범주 구분만으로도 정렬이 나올 수 있다). 이 시험은 복원 성능 향상을 말하지 않는다.
