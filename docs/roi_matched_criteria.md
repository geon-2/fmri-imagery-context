# 원본 캡션 기준선을 포함한 ROI 비교(E5): 복셀 수 맞춤, 피험자 1·2·5·7 — 판정 기준 (실행 전에 기록, 2026-10-14)

사용자 결정(2026-10-14): 맥락 라벨을 쓰는 것의 의의를 보려는 시험에는 원본 캡션과의 비교가 항상 있어야 한다. E4(`docs/roi_weight_criteria.md`)의 후속으로 (1) 모든 비교에 원본 캡션과 사물 이름을 같은 판정 기준으로 기준선에 넣고, (2) 복셀 수를 맞춘 ROI 비교를 하고, (3) 피험자 2·5·7에서도 같은 것을 본다. 숫자 기준은 제안이며 결과를 본 뒤 바꾸지 않는다. 탐색 단계.

## E4 결과에 대한 사후 관찰 (기준 없음, 근거로 쓰지 않음)
E4의 시험 A 자료를 다시 보면 피험자 1에서 places 그룹의 맥락 P1이 원본 캡션 P1과 같은 수준이었다(top-1 0.083 대 0.076, 차이 +0.007 [−0.004, +0.016]; top-5 0.243 대 0.246). 나머지 그룹은 원본 캡션이 높았다. 이것은 E4 결과를 본 뒤의 관찰이고 사전 가설이 아니므로, 아래 시험이 이 관찰이 우연인지 확인하는 용도다. 이 관찰 자체를 결론에 쓰지 않는다.

## 고정하는 것
CLIP ViT-L/14 텍스트, 전처리 a(세션 z-score + 반복 신뢰도 ≥ 0.1; 피험자마다 따로 계산), 각 피험자의 학습용 이미지(shared1000 제외, 반복 3회 있는 이미지) 5겹, 같은 ridge decoding과 평가(후보 약 1,000장, top-1 주, top-5 함께, 동점 부분 점수). 타깃: orig_P1(원본 캡션), obj_P1(사물 이름), ctx_P1(맥락 라벨). 이번에는 차원별 타깃과 결합(E4의 B·C)은 하지 않는다.

## 시험 1: 복셀 수를 맞춘 그룹 비교 (피험자별)
- 그룹: ALL(R2∪R3), R2, R3, 세부 7개(faces, places, bodies, words, S_ventral, S_lateral, S_parietal). 모든 그룹에서 a로 고른 복셀 중 **500개를 무작위로 뽑아**(서로 다른 시드 3회) 같은 크기로 decoding한다. a로 고른 복셀이 500개 미만인 그룹은 그 피험자에서 제외하고 어떤 그룹이 빠졌는지 적는다.
- 같은 복셀 선택 규칙으로 「전체 복셀」(500개 제한 없음)의 세 타깃 점수도 함께 낸다. 피험자 간에 K1(맥락 − 사물)과 K2(맥락 − 원본)가 피험자 1과 같은지 보는 기준선이다.
- 3회 뽑기의 이미지별 점수를 평균한 뒤 부트스트랩(이미지 단위 1,000회, 쌍 비교)한다.

## 판정
1. **K1, K2 재현(전체 복셀, 피험자별):** 피험자 1에서 K1은 +0.10대(차이 있음), K2는 −0.03대(원본이 높음, 차이 있음)였다. 같은 부호이고 구간이 0 제외 + |차이| ≥ 0.02이면 「재현」, 아니면 「재현 안 됨」으로 피험자마다 적는다.
2. **그룹별 맥락 − 원본 (복셀 수 500 고정):** Δ_g = (맥락 P1 − 원본 P1)의 top-1·top-5 차이. 그룹 g에서 Δ_g의 구간이 0을 포함하면 「맥락 ≈ 원본」, 0 위이면 「맥락이 높음」, 0 아래이면 「원본이 높음」.
3. **그룹별 상대 위치:** DD_g = Δ_g − Δ_ALL(500). 구간이 0 위이고 top-1 ≥ 0.01(top-5는 0.02)이면 「g는 ALL보다 맥락 쪽으로 기움」, 구간이 0 아래이고 같은 크기 이상이면 「원본 쪽으로 기움」, 아니면 「차이 없음」. (복셀 500개에서는 점수 자체가 낮아 기존 기준 0.02, 0.03을 쓰면 판정이 거의 나오지 않으므로 절반 크기로 정했다.)
4. **피험자 일관성:** 어떤 그룹이 「맥락 쪽으로 기움」 또는 「원본 쪽으로 기움」이라는 말은 4명 중 3명 이상에서 같은 방향일 때만 쓴다. 그 외에는 「일관되지 않음」으로 쓴다. places가 「맥락 쪽으로 기움」으로 나오는지는 이 규칙으로만 판단한다.
5. **사물 이름 대비:** 같은 방식으로 맥락 − 사물(K1 유사)과 원본 − 사물을 그룹별로 보고한다.
6. **셔플 대조:** 피험자별로 ALL에서 셔플 맥락 P1 top-1 ≤ 0.005이어야 한다. 넘으면 그 피험자 결과를 쓰지 않는다.
7. 어떤 그룹도 기준 3·4를 만족하지 못하면 「복셀 수를 맞추면 ROI에 따라 맥락 라벨이 원본 캡션보다 상대적으로 유리해진다는 근거가 없다」고 쓴다.

## 한계 (사전)
복셀 500개 무작위 추출은 그룹마다 전체 복셀에서 같은 비율을 쓰지 않으므로, 그룹 안에서 정보가 많은 복셀이 빠질 수 있다(3회 평균으로 줄이지만 없애지는 못한다). 그룹이 서로 겹친다. 피험자마다 a로 고른 복셀 수와 신뢰도가 다르다. 피험자 4명은 적은 표본이다. 이번에 보는 것은 지각 decoding이고, 최종 목적인 mental imagery 전이와는 다르다. 지각 decoding에서 원본 캡션이 높다는 사실만으로 맥락 라벨이 불리하다고 결론 내릴 수 없다(캡션에는 사물 정보가 들어 있다). 「캡션에서 사물 정보를 뺀 것」 비교(`ctxres_P1` 등)는 정의를 먼저 확인한 뒤 따로 다룬다.
