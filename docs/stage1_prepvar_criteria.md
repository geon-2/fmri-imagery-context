# 1단계 텍스트 표현 비교를 전처리 a와 d로 반복: 판정 기준 (실행 전에 기록, 2026-10-13)

사용자 결정(2026-10-13): 1단계의 통제변인(복셀 쪽)은 새 잡음 제거 방법(E3)이 아니라 E1에서 쓴 전처리 변형으로 맞춘다. 전처리 a와 d로 1단계를 다시 돌린다. E3(PCA·스무딩·백색화)는 부가 탐색으로 남기고 결론에 쓰지 않는다.

## 설계 원칙 (사용자, 기록)
축을 찾는 방법론, 타깃(텍스트)을 다루는 방식, 전처리 여부, 파이프라인 구조는 서로 의존한다. 어느 것을 먼저 정할지가 모호하므로 원칙적으로는 모든 조합을 돌려 본다. 파이프라인 구조는 의존적이지만 가장 마지막에 정한다. 이번 실행은 그 조합 중 「타깃 처리 × 전처리(a, d)」 칸이다. 다른 칸(축 방법, 구조)은 아직 비어 있다.

## 고정하는 것
`docs/stage1_text_repr_criteria.md`와 같다. 피험자 1, 학습용 이미지 4,999장 5겹, 같은 폴드·같은 ridge decoding·같은 평가(top-1 주, top-5 함께, 동점 부분 점수). 표현 orig_P1, orig_V2, obj_P1, obj_V2, ctx_P1, ctx_V2, obj_P1+ctx_P1, 셔플 대조, CLIP에는 ctx_T10 추가. 인코더 CLIP과 MPNet(인코더 선정 규칙용). 전처리 a(세션 z-score + 반복 신뢰도 ≥ 0.1, 6,728개)는 이미 계산된 결과를 그대로 쓴다. 새로 계산하는 것은 전처리 d(세션 z-score + 영역별 SNR 상위 20%, 약 4,087개)뿐이다.

## 주의
E1에서 d는 a의 더 엄격한 임계값과 수학적으로 같은 순서를 낸다(d ⊂ a). 따라서 a와 d는 독립된 두 전처리가 아니라 「같은 방식의 선택 강도 두 단계」다. 결과가 같더라도 선택 방식 전반에 둔감하다는 뜻은 아니다.

## 판정 (숫자는 제안이며 결과를 본 뒤 바꾸지 않는다)
1. 표현별 top-1·top-5 점수와 d − a 차이(같은 이미지 쌍 부트스트랩 1,000회). 구간이 0 제외 + top-1 ≥ 0.02(top-5는 0.03)이면 「변함」, 아니면 「같음」.
2. 핵심 대비 K1(맥락 P1 − 사물 P1), K2(맥락 P1 − 원본 P1), K3, K5(T10 − 맥락 P1), K6, K4의 판정(차이 있음/동등)이 a와 d에서 같은지.
3. 표현 순위: 8개 표현(T10 포함 9개)의 top-1 순위 Kendall τ(a, d). τ ≥ 0.9이면 「순위 유지」.
4. 인코더 선정 규칙(MPNet − CLIP, 핵심 표현 3개 중 2개 이상에서 구간이 0 위이고 ≥ 0.02이면 MPNet 논의)이 d에서도 같은지.
5. 셔플 대조 top-1 ≤ 0.005이어야 하고 넘으면 d 결과를 쓰지 않는다.
6. 결론 문장: 모든 판정이 같으면 「1단계 결론은 a와 d(선택 강도 두 단계)에서 유지」, 하나라도 다르면 어느 대비가 어떻게 달라졌는지 그대로 적는다.

## 한계 (사전)
한 피험자, 선택 강도 두 단계만(b·c는 포함하지 않음). 복셀 선택 외의 전처리 요인(축 방법, 구조)은 이번에 보지 않는다. 탐색 단계.
