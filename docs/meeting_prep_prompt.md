# 미팅 준비 프롬프트 (2026-10-15 미팅용, 새 세션에 그대로 붙여 넣기)

```
너는 한국어 캡스톤 연구("떠올린 장면에 남는 맥락": perception fMRI에서 저차원 맥락 축을 구해 mental imagery로 전이)의 미팅 준비를 돕는다. 내일 미팅에서 쓸 자료를 만든다. 쉬운 말로 쓴다.

[연구 한 줄]
목표는 맥락 라벨을 어떻게 쓰면 원본 COCO 캡션을 넘는 복원 성능을 낼 수 있는가이다. NSD 피험자 1·2·5·7, CLIP ViT-L/14 텍스트, 평가는 보류 이미지 약 1,000장 중 본 이미지 1장 찾기(top-1 주, top-5 함께, 동점 부분 점수).

[지켜야 할 규칙 — 사용자가 직접 정한 것]
- 사실만 쓴다. 이유·의도를 지어내지 않는다(왜 그렇게 했는지 기록에 없으면 「기록 없음」이라고 쓴다). 해석은 「가설, 확인 전」으로 표시한다.
- 결과를 본 뒤 기준을 바꾼 것처럼 쓰지 않는다. 모든 판정은 실행 전 기준 그대로다. 탐색 단계(피험자 1 또는 4명, 지각 decoding)라고 표시한다.
- 확인된 논문만 인용한다. 확인 못 한 인용은 쓰지 않는다.
- 사용자가 요청하지 않은 약속·계획·전망을 넣지 않는다.
- imagery 세트 B(자연 장면)의 반응은 열지 않았다. 열었다고 쓰지 않는다.
- 단계별로 환경을 고정하고 변인 하나만 바꾼다는 원칙을 설명할 때, 단계끼리 의존해서 되돌아가서 다시 하는 것이 정당하다는 점도 같이 쓴다.

[핵심 결과 — 확인용 요약]
- A(피험자 1): 원본 캡션 top-1 0.169, 맥락 라벨 평균 0.135, 연결(V2) 0.121, 짧은 문장(T10) 0.115, 사물 이름 0.031. 연결 방식이 평균보다 높지 않았다. CLIP 이미지 0.137, ResNet-50 0.159, DINOv2 0.114.
- A(피험자 4명): 6차원 전부 0.120, 원본 캡션 0.161. 한 차원만·일부 차원·라벨 일부 중 6차원 전부보다 높은 조합 없음. 활동 차원이 가장 큼.
- B(피험자 4명, k=32): 맥락 라벨은 어떤 압축에서도 압축 없음보다 높지 않음. CCA는 CLIP 이미지(+0.048)·DINOv2(+0.042)에서 4명 모두 높음. 맥락 − 사물은 모든 압축에서 유지. 맥락이 원본을 넘은 경우 없음.
- 병목 encoder→z→decoder(perception 학습만): 주 k=64에서 풀 릿지 수준 유지(ctx 0.144 대 0.126, CLIP 이미지 0.134 대 0.135). imagery 세트 A·C는 양성 대조 실패로 검증 불가.
- 결론에 쓰지 않는 부가 탐색: 잡음 제거(E3), ROI 분할·차원 가중치(E4).
```
