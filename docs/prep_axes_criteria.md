# E1 전처리 강건성 점검, E2 축 방법 비교: 판정 기준 (실행 전에 기록, 2026-10-12)

공통: 피험자 1, 텍스트 임베딩은 MPNet, 학습용 이미지(shared1000 제외, 라벨이 있는 이미지)의 5겹 교차검증(탐색). shared1000은 이미 여러 번 봤으므로 이번에는 쓰지 않는다. 지표와 교차검증 방식은 `embedding_compare.py`와 같다(복셀별 alpha, 폴드별 열 평균 제거, 주 점수 P = R2·R3 복셀 r 중앙값의 평균, 이미지 단위 부트스트랩 1,000회). 결과를 본 뒤 기준을 바꾸지 않는다. 숫자 기준은 제안(사용자 확인 전)이다.

## E1. 전처리 강건성 (변형 4개)
| 변형 | 값 표준화 | 복셀 선택 |
|---|---|---|
| a (현재) | 세션 안 복셀별 z-score | 학습 반복 신뢰도 ≥ 0.1 |
| b | 세션 안 복셀별 z-score | 선택 없음(영역 마스크 전체) |
| c (MIRAGE식 최소) | 없음(NSD 베타 그대로) | 선택 없음 |
| d (Saha Roy식) | 세션 안 복셀별 z-score | 영역(R1, R2, R3, EARLY)별 SNR 상위 20%(SNR = 이미지 간 분산 대 반복 간 분산, 학습 반복만) |
반복 평균(3회)은 모든 변형에서 같다.
텍스트 조건: 원본 캡션 P1·V2, 사물 이름 P1, 맥락 P1·V2, 사물+맥락 P1, 맥락 P1 셔플 대조.
핵심 대비 4개: C1 맥락 P1 − 사물 P1, C2 맥락 P1 − 원본 P1, C3 (사물+맥락 P1) − 원본 P1, C4 맥락 V2 − 맥락 P1.
**판정**
- 대비별 강건: 4개 변형 모두에서 차이의 부호가 같고 95% 구간이 0을 제외하는지(포함하는지) 판정도 같으면 「강건」. 하나라도 다르면 「전처리 의존」.
- 순위 일관: 텍스트 조건 6개(셔플 제외)의 P 순위가 변형 쌍마다 Kendall τ ≥ 0.8이면 「순위 일관」.
- 이미지 부트스트랩으로 변형 쌍마다 대비 순서가 뒤집히는 비율을 보고.
**결과에 따른 규칙(사전)**: 핵심 대비 4개가 모두 강건이고 순위도 일관이면 「전처리는 결론에 영향이 없다」고 보고하고 주 설정은 a를 유지한다(기존 분석과 연속, c와 같은 결론임을 명시). 그렇지 않으면 의존한 대비를 변형별로 보고하고 주 설정은 사용자가 정한다.

## E2. 축 방법 비교 (decoding 방향 축 포함)
방법(같은 k, 같은 학습 이미지로만 축을 구한다): RRR(기존, 인코딩 방향), DDR(decoding 방향: 복셀 → 임베딩 ridge 예측값의 SVD 상위 k 출력 방향), PLS, CCA(복셀을 상위 PC 200개로 줄인 뒤 정규화 CCA), PCA, 무작위. k ∈ {1, 2, 3, 5, 8, 12, 20, 32, 50, 80, 128}. 전처리는 E1의 주 설정(a)을 쓴다.
지표: (1) encoding P(k차원 축 위에서 복셀을 OLS로 다시 적합, `axes_k_curve.py`와 같음), (2) decoding: 복셀에서 k개 축 좌표를 ridge로 예측해 임베딩을 복원하고, 보류 폴드 이미지끼리 1장 찾기 top-1, top-5(후보는 보류 폴드 전체, 약 1,000장).
**판정**
- DDR 대 RRR: k = 5, 12, 20에서 지표별 차이의 부트스트랩 95% 구간이 0을 제외하고 크기가 encoding P 0.01 이상 또는 decoding top-1 0.02 이상이면 「차이 있음」, 아니면 「동등」. 방향을 함께 보고.
- 모든 방법은 같은 k의 무작위 축보다 높아야 의미가 있다고 본다(미달이면 그 방법은 「무작위와 구분 안 됨」).
- 축 공간의 겹침(RRR 대 DDR 대 PCA, 평균 cos² of principal angles, 기대 무작위값 k/d 함께)을 보고.
