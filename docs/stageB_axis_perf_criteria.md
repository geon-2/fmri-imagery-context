# B 단계 추가: 축별 예측력과 축 선택 — 판정 기준 (실행 전에 기록, 2026-10-14)

`docs/stageB_compression_criteria.md`의 후속. 앞선 B 결과는 축 k개를 함께 쓴 성능만 보고했고, 축 하나하나가 복셀에서 얼마나 잘 예측되는지는 보지 않았다. 사용자 지적(2026-10-14): 축마다의 성능이 높은 것을 얘기해야 한다. 같은 환경(피험자 1, CLIP, 전처리 a, 전체 복셀, 5겹, 같은 폴드)과 같은 방법·타깃 종류를 쓴다. 숫자 기준은 제안이며 결과를 본 뒤 바꾸지 않는다. 탐색 단계.

## 측정
1. **축별 예측력 r:** 방법(RRR, DDR, CCA, PLS, PCA)과 타깃 종류(맥락 라벨, 원본 캡션, 사물 이름, CLIP 이미지, DINOv2, ResNet-50)마다 축 번호 1~128 각각에 대해, 보류 폴드에서 「복셀로 예측한 축 좌표」와 「실제 축 좌표」의 Pearson r을 구한다(폴드마다 보류 이미지 안에서 계산, 5폴드 평균과 폴드 간 표준편차를 함께 보고). 축은 폴드마다 학습 이미지만으로 구한다.
2. **무작위 대조:** 같은 타깃의 무작위 직교 방향 128개의 r 분포를 만든다. 「높은 축」은 무작위 분포의 95번째 백분위(폴드 평균 기준)를 넘는 축이다. 방법·타깃마다 높은 축의 수를 센다.
3. **안정성:** 상위 10개 축(r 기준, 축 번호 아님)이 폴드마다 같은 번호로 반복되는지(5폴드 중 몇 폴드에서 같은 번호가 상위 10에 들어가는지)를 보고한다. 번호는 방법이 정하는 중요도 순서와 같으므로, 이 번호 안정성은 「같은 순서의 축이 반복해서 잘 예측되는가」를 뜻한다. 서로 다른 폴드에서 구한 축이 같은 방향인지는 이번에 판정하지 않는다.
4. **축 선택(SEL):** 각 학습 폴드의 학습 이미지를 반으로 나눠 앞 절반으로 학습하고 뒤 절반에서 축별 r을 구해, 처음 128개 중 r이 높은 32개를 고른다. 이렇게 고른 32개 축으로(원래 순서의 앞 32개 대신) 최종 decoder를 학습 폴드 전체로 학습하고 보류 폴드에서 전체 타깃 공간 1장 찾기(top-1·top-5)로 평가한다. 보류 폴드는 선택에 쓰지 않는다.

## 판정 (이미지 단위 부트스트랩 1,000회 쌍 비교; 구간이 0 제외 + top-1 ≥ 0.02, top-5 ≥ 0.03이면 높음/낮음, 아니면 동등)
- SEL(32) − 앞 32개 축: 방법·타깃마다 판정.
- SEL(32) − 압축 없음: 방법·타깃마다 판정. 맥락 라벨에서 압축 없음(top-1 0.135, top-5 0.360)을 넘는지.
- 맥락 − 원본 캡션(SEL(32)): 압축 없음의 −0.034와 비교, 「추월」은 구간이 0 위이고 ≥ 0.02일 때만.
- 높은 축의 수와 축별 r 곡선은 사실만 보고한다. 「특정 축이 맥락이다」 같은 해석은 하지 않는다.
- 셔플 대조(타깃을 이미지 사이에서 섞음): SEL(32) top-1 ≤ 0.005.

## 한계 (사전)
축 하나의 r이 높다는 것이 이미지를 잘 구분한다는 뜻은 아니므로 합친 성능과 함께 본다. 반으로 나눈 학습 데이터로 구한 r은 노이즈가 있어 선택이 불안정할 수 있다. 피험자 1만. 무작위 대조의 95번째 백분위는 128개 값으로 구한 기준이라 거칠다. 이번 단계는 지각 decoding이다.
