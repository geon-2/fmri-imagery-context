# MIRAGE NSD-Imagery 벤치마크 재현 판정 기준 (초안, 최종 실행 전)

작성: 2026-10-25. 이 기준은 최종 설정의 생성 결과를 평가하기 **전에** 정한다(`CLAUDE.md`의 "기준을 결과 뒤에 맞추지 않는다" 원칙). 아래 숫자는 제안이며 사용자가 승인한 뒤에 확정한다.

## 재현 대상
논문(arXiv 2605.17198) Table 1의 **MIRAGE, Mental Imagery Reconstructions** 행(simple + complex 자극 12개).
PixCorr 0.104, SSIM 0.398, Alex(2) 63.92%, Alex(5) 62.46%, Incep 52.25%, CLIP 57.46%, EffNet-B 0.914, SwAV 0.575.
(brain correlation 3개, 캡션 4개는 구현 전이라 이번 판정에서 제외. 사람 평가(Table 2, Fig 3, 4A)는 평가자 모집이 불가능해 제외.)

## 평가 방법
`src/eval/nsd_imagery_eval.py`의 `official` 값을 쓴다. 공식 평가 노트북의 함수를 그대로 복사해 대조했고 7개 지표가 소수 5자리까지 일치했다(SwAV는 대조 못 함).
지표는 자극(12개) → 반복 순으로 평균한다. 공식 노트북은 반복마다 계산해 평균한다.

## 판정 규칙 (제안)
1. **지표별**: 우리 평균(반복 평균 → 자극 평균)의 95% 구간(자극 12개 복원추출 5000회)을 구하고, **논문 값이 그 구간 안에 들어가면 그 지표는 "논문 값과 구분되지 않음"**으로 적는다.
2. **전체**: 8개 지표 중 **6개 이상**이 "구분되지 않음"이면 "벤치마크 수치가 재현되었다(이번 설정 범위에서)"고 적는다. 5개 이하이면 "재현되지 않았다"고 적고 어떤 지표가 어긋났는지 적는다.
3. 구간은 자극 변동만 반영한다. 반복과 피험자 변동은 포함하지 않으므로 구간이 실제보다 좁을 수 있다. 이 한계를 결과와 같이 적는다.
4. 위 숫자(6/8)와 구간 방식은 임의로 정한 제안이다. 논문이 오차를 보고하지 않아 근거 있는 임계값이 없다.

## 하지 않는 주장
- 사람 평가(Table 2)의 재현.
- brain correlation, 캡션 지표의 재현.
- 피험자 평균 여부가 불확실한 상태에서 Table 1과의 "정확한" 일치.
