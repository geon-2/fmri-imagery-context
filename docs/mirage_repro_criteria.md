# MIRAGE NSD-Imagery 벤치마크 재현 판정 기준 (초안, 최종 실행 전)

상태: 실행 계획(A+B)은 사용자가 2026-10-25에 승인했다. 판정 규칙(구간 방식, 6/8 임계값)은 아직 사용자가 명시적으로 승인하지 않았다. 최종 결과를 보기 전에 확정한다.

작성: 2026-10-25. 이 기준은 최종 설정의 생성 결과를 평가하기 **전에** 정한다(`CLAUDE.md`의 "기준을 결과 뒤에 맞추지 않는다" 원칙). 아래 숫자는 제안이며 사용자가 승인한 뒤에 확정한다.

## 재현 대상
논문(arXiv 2605.17198) Table 1의 **MIRAGE, Mental Imagery Reconstructions** 행(simple + complex 자극 12개).
PixCorr 0.104, SSIM 0.398, Alex(2) 63.92%, Alex(5) 62.46%, Incep 52.25%, CLIP 57.46%, EffNet-B 0.914, SwAV 0.575.
(brain correlation 3개, 캡션 4개는 구현 전이라 이번 판정에서 제외. 사람 평가(Table 2, Fig 3, 4A)는 평가자 모집이 불가능해 제외.)

## 평가 방법
`src/eval/nsd_imagery_eval.py`의 `official` 값을 쓴다. 공식 평가 노트북의 함수를 그대로 복사해 대조했고 7개 지표가 소수 5자리까지 일치했다(SwAV는 대조 못 함).
지표는 자극(12개) → 반복 순으로 평균한다. 공식 노트북은 반복마다 계산해 평균한다.

## 판정 규칙 (2026-10-25 확정)
**확정 경위(투명하게 적음)**: 피험자 2의 5회 반복 결과를 본 뒤에, 사용자가 "그 결과를 보고 적당히 정하라"고 지시해 정했다. 따라서 이 기준은 결과를 보기 전에 정한 것이 아니다(`CLAUDE.md`의 사전 기준 원칙에서 사용자 지시로 벗어남). 임계값은 결과에 맞추지 않고 관습적인 숫자(15%)와 구간 규칙을 쓰되, 이 사실을 최종 결론과 같이 적는다. 피험자 2 한 명의 값은 이 규칙으로 7개 지표 중 6개가 15% 이내라서(Incep만 +21%) 이 기준은 그 결과와 독립적이지 않다. 최종 판정은 피험자 4명(+retrieval)으로 계산한 값으로 한다.

1. **주 규칙(상대 차이)**: 지표별로 |우리 평균 − 논문 값| / 논문 값 ≤ **15%**이면 그 지표는 "논문과 일치". 낮을수록 좋은 지표(EffNet-B, SwAV)도 같은 식.
2. **전체**: 계산한 지표 중 **75% 이상**(8개면 6개, 7개면 6개)이 일치하면 "벤치마크 수치가 재현되었다(이번 설정 범위에서)"고 적는다. 그보다 적으면 "재현되지 않았다"고 적고 어긋난 지표를 적는다.
3. **참고 규칙(구간)**: 우리 평균의 95% 구간(자극 12개 복원추출 5000회)에 논문 값이 드는지도 같이 표시한다. 자극이 12개뿐이라 구간이 넓어 구분력이 약하다(서로 다른 설정을 합친 임시 결과도 7개 모두 "구간 안"이었음). 이 규칙만으로 재현이라고 적지 않는다.
4. 구간은 자극 변동만 반영한다. 반복과 피험자 변동은 포함하지 않으므로 실제보다 좁을 수 있다. 이 한계를 결과와 같이 적는다.
5. 15%와 75%는 근거 있는 임계값이 아니다. 논문이 오차를 보고하지 않았다.
