# 1단계 텍스트 표현 비교(decoding 주 지표) 판정 기준 (실행 전에 기록, 2026-10-13)

사용자 결정(2026-10-13): 표현을 고르는 비교는 decoding을 주 지표로 하고 encoding은 보조로 낸다. 텍스트 인코더는 CLIP ViT-L/14 텍스트(10/1 사전 결정)를 기준으로 진행하고, MPNet을 같이 돌려 인코더 선정 규칙에 쓴다. 전처리는 현재 설정(a)으로 고정한다. 숫자 기준은 제안(사용자 확인 전)이며 결과를 본 뒤 바꾸지 않는다.

## 설정
- 피험자 1, 전처리 a(세션 z-score + 학습 반복 신뢰도 ≥ 0.1, 복셀 6,728개 중 R2·R3 영역), 학습용 이미지 4,999장(shared1000 제외), 5겹 교차검증(탐색, 확인 단계 없음).
- decoding: 보류 폴드에서 복셀 → 텍스트 임베딩(전체 차원) ridge(정규화 강도는 학습 폴드 안 3겹으로 타깃별 선택, 범위 1e2~1e7). 보류 폴드 이미지(약 1,000장)끼리 1장 찾기: 예측 임베딩과 각 후보의 임베딩의 코사인(차원별로 보류 폴드의 실제값 평균·표준편차로 표준화).
- 동점 처리: 후보 임베딩이 정답과 같아 점수가 같으면(예: 같은 사물 목록) top-1은 1/(1+동점 수), top-5는 (5 − 더 높은 후보 수)/(1+동점 수)를 0~1로 잘라 부분 점수로 준다.
- 점수: top-1(주), top-5. 우연 수준 1/후보 수(약 0.001).

## 표현 (각 인코더에서 같은 규칙)
orig_P1(원본 캡션 5개 각각 임베딩 평균), orig_V2(캡션을 이은 문자열 하나), obj_P1, obj_V2(사물 이름 문자열), ctx_P1(맥락 구별 평균), ctx_V2(구를 이은 문자열 하나), objctx_P1(사물 P1 + 맥락 P1을 붙인 특징), 셔플 대조 ctx_P1_shuf(항목 수가 같은 이미지끼리 텍스트를 바꿈).
추가 예정: T10(같은 맥락 구를 새 정보 없이 짧은 문장으로 연결, CLIP 77토큰 안으로 맞춤). 규칙: 구를 place_type, environment, activity, scale, implied_event, notes 순으로 ", "로 이어 붙이되 CLIP 토큰이 75를 넘으면 그 구부터 뒤를 버린다(새 단어를 더하지 않음). 버려지는 구 비율을 보고한다. 새 임베딩 계산이 필요해 별도 실행.

## 핵심 대비 (CLIP 기준, 주 지표 top-1)
K1 ctx_P1 − obj_P1, K2 ctx_P1 − orig_P1, K3 ctx_V2 − ctx_P1, K4 objctx_P1 − orig_P1, K5 T10 − ctx_P1(T10 계산 후).
판정: 이미지 단위 부트스트랩(1,000회, 쌍 비교는 같은 표본) 95% 구간이 0을 제외하고 |차이| ≥ 0.02이면 「차이 있음」(방향 보고), 아니면 「동등」.
CLIP에서 V2·T10 조건은 77토큰 제한을 받으므로 잘린 비율을 같이 적고, 해석에 「잘림의 영향 포함」임을 명시한다.

## 검증 대조
- 셔플 대조 top-1 ≤ 0.005이어야 하고, 넘으면 파이프라인 오류로 보고 결과를 쓰지 않는다.
- 모든 실제 표현은 우연 수준 이상이어야 한다.

## 인코더 선정 규칙 (CLIP 기본 유지, 교체 조건)
핵심 표현 3개(orig_P1, ctx_P1, objctx_P1)에서 MPNet top-1 − CLIP top-1(같은 표본 부트스트랩)이 ≥ 0.02이고 구간이 0을 제외하는 것이 2개 이상이면 「MPNet 선정 논의」, 아니면 「CLIP 유지」. MPNet은 점수와 별개로 text-only 비교 민감도로 남긴다.

## 보조 지표와 한계
- encoding P(E1 변형 a와 같은 방식, 같은 표현)와 decoding 순위의 Kendall τ를 보고한다.
- 서로 다른 표현은 임베딩 공간이 달라 「각자 공간에서의 찾기 정확도」의 난이도가 다르다. 공통 기준(사진-캡션 공통 공간 등)은 이번에 설계하지 않는다(열어 둔 항목).
- 탐색 단계(피험자 1, 학습용 이미지 교차검증)이고 확인(shared1000, 다른 피험자)은 하지 않는다.
