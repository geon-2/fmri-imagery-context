# 잡음 제거를 적용한 1단계 decoding 반복(E3): 판정 기준 (실행 전에 기록, 2026-10-13)

사용자 요청(2026-10-13): 잡음 제거를 적용하고 1단계 decoding 비교를 다시 한다. top-5도 함께 보고한다. 해석: 추가 BOLD 잡음 제거 방법을 복셀 값에 적용한 뒤 `docs/stage1_text_repr_criteria.md`와 같은 decoding 평가를 반복한다. 방법은 새 다운로드 없이 로컬에서 할 수 있는 것만 쓴다(NSD 베타 b1·b2 비교는 제외, 후보로 남김). 숫자 기준은 제안이며 결과를 본 뒤 바꾸지 않는다.

## 고정하는 것
피험자 1, 전처리 a(세션 z-score, 반복 신뢰도 ≥ 0.1)로 고른 복셀 6,728개를 모든 조건에서 그대로 쓴다(복셀 집합을 같게 해서 값 변화만 비교). 학습용 이미지 4,999장 5겹, 같은 폴드·같은 ridge decoding·같은 평가(top-1 주, top-5 함께, 동점 부분 점수, 후보 약 1,000장). 인코더 CLIP ViT-L/14 텍스트. 표현: orig_P1, obj_P1, ctx_P1, obj_P1+ctx_P1, ctx_V2, ctx_T10, 셔플 대조(ctx_P1_shuf).

## 조건 (D0 = 기준, 이미 계산된 현재 결과)
- **D1 PCA 잡음 제거:** 학습 폴드의 반복 평균 반응에서 PC를 구해 상위 k개만 남기고 재구성(학습·보류 모두 학습 폴드의 PC에 투영). k = 100, 300, 1000을 모두 보고(선택하지 않음).
- **D2 공간 스무딩:** 복셀 3D 좌표로 가우시안 평균(R2∪R3 마스크 안의 이웃만). FWHM 1, 2 복셀(1.8, 3.6 mm). 모든 반복에 적용한 뒤 3회를 평균하고 D0와 같은 복셀 6,728개만 쓴다. 라벨을 쓰지 않고 학습·평가 구분이 필요 없다.
- **D3 잡음 백색화:** 학습 폴드의 같은 이미지 3회 반복 편차로 복셀 간 잡음 공분산을 구하고(수축 α = 0.5, 수축 대상은 복셀별 분산만 남긴 대각 공분산: Σ_s = (1−α)Σ + α·diag(Σ)), 그 역제곱근으로 학습·보류 반응을 변환.

## 판정
- 조건별·표현별 top-1 차이(D − D0, 이미지 단위 부트스트랩 1,000회 쌍 비교): 구간이 0 위이고 ≥ +0.02이면 「개선」, 구간이 0 아래이고 ≤ −0.02이면 「악화」, 아니면 「동등」. top-5도 같은 방식으로 보고(기준 크기 0.03).
- 표현 순위·핵심 대비의 유지: K1(맥락 − 사물), K2(맥락 P1 − 원본 P1), K5(T10 − 맥락 P1)의 판정이 D0와 같은지 조건별로 보고.
- 셔플 대조 top-1 ≤ 0.005이어야 하고 넘으면 그 조건 결과를 쓰지 않는다.

## 누수 방지
PCA 성분, 잡음 공분산, 백색화 행렬은 학습 폴드의 이미지에서만 구한다. 스무딩은 복셀 좌표만 쓴다.

## 한계 (사전)
복셀 집합을 a로 고정해 「선택 + 잡음 제거」의 결합 효과는 보지 않는다. 방법별 모수(k, FWHM, α)는 한 점씩만 본다. 탐색 단계(피험자 1)이고 NSD 베타 b1·b2 비교(잡음 제거 강도)는 포함하지 않는다.
