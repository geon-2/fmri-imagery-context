# A 단계 확장: 타깃 종류 비교(텍스트 대 이미지 표현) — 판정 기준 (실행 전에 기록, 2026-10-14)

사용자 결정(2026-10-14): 피험자는 글이 아니라 이미지를 본다. CLIP·CNN 등으로 표현한 것은 우리가 해석하려고 쓰는 도구이므로, 타깃을 캡션이나 맥락 같은 텍스트로 두는 것이 맞는지 이미지 기반 타깃과 같은 조건에서 비교해 본다. `docs/stage_structure.md`의 A 단계로 되돌아가 변인을 「텍스트를 다루는 방식」에서 「타깃 종류」로 넓힌다. 숫자 기준은 제안이며 결과를 본 뒤 바꾸지 않는다. 탐색 단계.

## 고정하는 것
피험자 1, 전처리 a(6,728 복셀), 학습용 이미지 4,999장 5겹(같은 폴드), 같은 ridge decoding(타깃마다 alpha는 학습 폴드 안 3겹으로 선택), 같은 평가(보류 폴드 약 1,000장 중 본 이미지 1장 찾기, top-1 주·top-5 함께, 동점 부분 점수, 코사인 유사도는 보류 폴드 평균·표준편차로 차원 표준화). 이미지 표현은 라벨·캡션과 무관한 이미지 파일에서 얻는다.

## 타깃 종류(바꾸는 변인)
- 텍스트(이미 계산됨): 원본 캡션 P1(orig_P1), 사물 이름 P1(obj_P1), 맥락 라벨 P1(ctx_P1). CLIP ViT-L/14 텍스트.
- 이미지, 언어와 같은 공간: CLIP ViT-L/14 이미지 임베딩(이미지 인코더 출력, 768차원, L2 정규화).
- 이미지, 언어 없이 학습한 시각 표현: DINOv2(기본 크기)의 [CLS] 출력, ResNet-50의 전역 평균 풀링 특징(2,048차원). 모델 가중치는 공개 사전학습 가중치를 쓴다(다운로드 필요 시 사용자 승인 후).
- 모든 이미지 표현은 224 해상도 중심 자르기와 각 모델의 표준 전처리를 쓴다. 학습 이미지 4,999장 전부에 대해 한 번만 계산한다.

## 비교의 성격 (사전 주의)
같은 과제 「본 이미지를 후보 중에서 찾기」 안에서 타깃 종류를 비교한다. 텍스트 타깃은 같은 라벨을 가진 이미지끼리 임베딩이 같아져 정답을 구분하는 데 상한이 있고(사물 이름 상한 0.579), 이미지 타깃은 이미지마다 값이 달라 이 상한이 없다. 따라서 이미지 타깃이 더 높게 나오는 것은 기대되는 결과이며, 그 차이를 「뇌가 이미지로 처리한다」거나 「텍스트가 틀렸다」는 근거로 쓰지 않는다. 이 비교는 타깃 선택이 복원 가능성에 미치는 영향을 같은 잣대로 보여 주는 용도다. 사물 정보를 담고 있는 이미지 타깃은 원본 캡션과 같은 성격의 기준선이다.

## 판정 (이미지 단위 부트스트랩 1,000회 쌍 비교; 구간이 0 제외 + top-1 ≥ 0.02, top-5 ≥ 0.03이면 높음/낮음, 아니면 동등)
1. 타깃 종류별 top-1·top-5 표(우연 수준 약 0.001 함께).
2. 이미지 타깃 − 원본 캡션, 이미지 타깃 − 맥락 라벨, 이미지 타깃끼리(CLIP 이미지 − DINOv2 − ResNet)의 차이.
3. 셔플 대조: 각 타깃에서 타깃 행을 무작위로 섞어 같은 방식으로 평가. top-1 ≤ 0.005이어야 하고 넘으면 그 타깃 결과를 쓰지 않는다.
4. 결론은 사실만 쓴다. 「이미지 타깃이 맥락 라벨보다 높다/낮다/동등」과 그 크기. 상한이 다르다는 점을 함께 적는다.

## 이후 단계에 반영(기록)
B 단계(압축·축)의 같은 시험을 모든 타깃 종류에 반복해, 압축 이득이 타깃 종류와 무관한지(복셀 잡음 줄임) 맥락 타깃에서만 큰지 본다. 맥락 라벨 결합 타깃(차원별)은 C 단계, 이미지와 텍스트를 함께 쓰는 구조는 D 단계 변인이다.

## 한계 (사전)
피험자 1. 이미지 모델 3개는 한 시점의 선택이며 다른 모델은 보지 않았다. 해상도·자르기가 모델마다 달라 화면 일부가 잘릴 수 있다. 모델마다 임베딩 차원과 구분력이 다르다. 지각 decoding이고 imagery 전이가 아니다.
