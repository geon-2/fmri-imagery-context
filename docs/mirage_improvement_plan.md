# MIRAGE 개선 플랜 (초안, 2026-10-27)

사용자가 정리한 세 방향을 MIRAGE 파이프라인의 어느 부분에 붙이는지 적는다. 모든 항목은 **제안**이고 판정 기준은 실행 전에 따로 적는다(`CLAUDE.md`). 이 문서는 재현 실행 기록(`docs/mirage_server_run_log.md`)의 기준선 위에서 시작한다.

## 출발점(측정한 사실)
- 기준선: MIRAGE 원본 파이프라인, 40세션, 피험자 2·5·7(retrieval 없음, 반복 5회), 피험자 1(retrieval 후보 16, 반복 3회 진행 중 + retrieval 없음 5회). 공식 평가 방식 7개 지표 4명 평균이 논문 값과 상대 차이 8% 이내(중간 결과).
- 비용(실측): 학습 피험자당 약 50분(retrieval 없음), 생성 이미지당 약 2분(A2000), retrieval 후보 16장이면 시드당 약 9시간 40분. 학습 메모리 피크 46~49GB(lean ridge 사용), 가중치(float32 기준 추정) text 6.2GB, blurry(VDVAE) 5.7GB, retrieval 16.5GB.
- MIRAGE는 ROI를 나누지 않고 nsdgeneral 전체 복셀을 쓴다(Notion 문헌 교차검증 노트).

## 방향 1: ROI별 처리로 decoder 분리
- **붙이는 곳**: 릿지 decoder 4종(이미지 CLS 768, 텍스트 77×1280, VDVAE 91168, retrieval 257×1024)을 복셀 전체에 하나씩 학습하는 부분. ROI(초기 시각 대 고차)마다 따로 학습하고 출력을 합침.
- **자연스러운 가설(근거는 문헌, 우리 데이터로는 미검증)**: 저수준 타깃(VDVAE)은 초기 시각 영역, 의미 타깃(CLIP, 텍스트)은 고차 영역에서 더 잘 읽힌다. imagery는 고차 영역과 더 정렬된다는 문헌(논문 3.1절의 해석)이 있다.
- **통제**: (a) 같은 복셀 수의 무작위 ROI, (b) 복셀 전체 하나의 decoder(기준선), (c) ROI별 decoder 출력을 평균하는 앙상블과 파라미터 수를 맞춘 대조.
- **기존 자원**: perception에서 ROI별 decoding 시험(E4, E5)은 탐색 단계로 끝났고 imagery ROI별 평가는 안 했다.

## 방향 2: context용 decoding model 추가 + 복셀 압축 후 적용
- **붙이는 곳**: 기존 decoder 묶음에 맥락 임베딩을 예측하는 decoder를 추가해 Stable Cascade의 텍스트 조건(77×1280, CLIP bigG 공간) 또는 별도 가이던스로 합침. 복셀 쪽은 B 단계 방법(VPCA, RRR, CCA 등)으로 압축한 뒤 적용.
- **통제**: 원본 + 셔플한 맥락, 원본 + 같은 크기의 더미 decoder(타깃·decoder를 늘리는 효과 분리), 원본 캡션 단독.
- **알려진 위험**: 기존 단계 실험에서 맥락 라벨이 원본 캡션을 넘는 조합이 4명 어디에서도 없었고, 압축이 맥락 라벨 decoding을 높인다는 근거도 없었다(CCA는 이미지 타깃에서만 이득). 맥락을 MIRAGE의 텍스트 조건 공간(bigG, LLaVA 긴 캡션 기반)으로 옮기는 방법은 미정.

## 방향 3: 입력·출력 차원 축소(저차원 축)로 학습·생성 효율 개선
- **붙이는 곳**: 입력(복셀 약 15.7k)과 출력(텍스트 98,560, VDVAE 91,168, retrieval 263,168 차원) 모두. 출력은 k개 축으로 줄여 예측한 뒤 원래 차원으로 복원.
- **효과가 기대되는 것과 아닌 것**: 가중치 크기, 학습 메모리, 학습 시간은 줄 수 있다(retrieval 가중치만 16.5GB). 반면 **생성 시간은 거의 줄지 않는다**(이미지당 약 2분은 Stable Cascade 샘플링이 대부분이고 decoder 차원과 무관). 다만 retrieval 후보를 줄이면 생성이 후보 수에 비례해 준다.
- **평가**: 성능을 지키는지(공식 지표, 기준선 대비 짝지은 비교)와 자원(메모리, 시간, 가중치 크기)을 같이 보고한다.

## 독립 항목
- encoder–decoder 병목 구조(복셀을 z로 압축하고 z에서 복원)는 MIRAGE 개선과 별개 연구선으로 다룬다. perception에서는 k≥64까지 유지됐고 imagery 검증은 안 됐다.

## 평가 틀(공통)
- 기준선과 개선안을 같은 피험자(1, 2, 5, 7), 같은 시드로 짝지어 평가. (피험자, 자극) 쌍 48개를 복원추출해 신뢰구간(구현 필요).
- 순서: 지각 데이터에서 식별 점수 수준으로 먼저 → 통과하면 diffusion 복원(생성은 이미지당 약 2분).
- 12개 자극의 검정력이 낮으므로 가능하면 shared1000(비전)에서도 확인.

## 열린 질문
- 세 방향의 우선순위와 순서.
- 방향 2에서 맥락을 넣는 위치(텍스트 조건 대체, 추가 가이던스, 캡션 보강).
- 각 방향의 사전 판정 기준(실행 전).
