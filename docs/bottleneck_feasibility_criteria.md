# 병목 encoder–decoder의 가능성 점검(imagery가 perception 압축 부분공간에 있는가) — 판정 기준 (실행 전에 기록, 2026-10-14)

사용자 정리(2026-10-14): perception fMRI를 decoding 방향으로 압축해(encoder) 그 출력 z만 decoder의 입력으로 쓰는 구조에서, imagery 활동이 이 압축 부분공간 안에 있다면 imagery를 같은 encoder에 통과시켜도 정보와 성능이 유지된다는 가설. 이번 시험은 본 연구 결과를 내기 전에 **가능성이 있는지만 보는 사전 점검**이다. 실제 학습·성능 평가(복원 성능 비교)는 하지 않는다. 숫자 기준은 제안이며 결과를 본 뒤 바꾸지 않는다. 탐색 단계. 배경: Notion 「압축 테스트 목록」의 복셀 쪽 병목 decoder(E-A~E-E), T3(imagery 정렬).

## 데이터와 약속
- 피험자 1·2·5·7. perception: 각 피험자의 학습용 이미지(shared1000 제외, 반복 3회) 4,955~4,999장, 전처리 a로 고른 복셀(세션 z-score + 반복 신뢰도 ≥ 0.1)만 사용.
- imagery: NSD-Imagery **세트 A(도형)와 C(단어)의 imagery run과 같은 세트의 viewing run만** 쓴다. **세트 B(자연 장면)의 imagery 반응은 읽지 않는다**(평가용으로 기준을 먼저 적은 뒤 한 번만 열기로 한 약속). 모든 imagery 분석은 perception으로 학습한 encoder를 고정한 채 적용만 한다(imagery 데이터로 학습하지 않음).
- imagery 베타 전처리: 복셀마다 해당 피험자의 imagery 실험 전체 시행(720)에서 z-score. 같은 복셀 집합(a로 고른 것)만 사용.
- 단위: 피험자 4명 × 세트 2개 = 8단위. 세트마다 target 6개, imagery 2 run(각 target 8회 평균), viewing 1 run(홀짝 반으로 나눠 평균).

## encoder (perception으로만 학습)
- 지도형 병목(E-A): perception 복셀(표준화) → 타깃 임베딩 ridge(λ = 1e4로 고정, E2의 DDR에서 선택된 값) 적합값의 SVD로 임베딩 공간의 상위 k개 방향 V_k를 구하고, 복셀 공간의 encoder 방향 U_k = orth(W·V_k)(복셀 × k)를 얻는다. z = 복셀 패턴 · U_k.
- 타깃: 주 encoder는 ctx_P1(맥락 라벨 P1), 비교로 orig_P1, CLIP 이미지 임베딩.
- k: 16, 32, 64 모두 보고. 주 k = 32(결과를 보기 전에 고정).
- 대조 부분공간(같은 k): (a) 무작위 직교 방향(500회), (b) 복셀 PCA 상위 k(비지도 병목, E-B).

## 측정
1. **양성 대조:** viewing run의 target 식별(홀짝 반 평균 사이 상관, 6개 중 1, 우연 1/6)이 전체 복셀과 encoder z에서 우연보다 높은가.
2. **imagery 신호 존재:** imagery run 1 대 run 2 target 식별(전체 복셀, 우연 1/6)이 우연보다 높은가. 이것이 없으면 병목 검증이 불가능하다.
3. **정렬 비율:** 세트 안에서 target 평균을 뺀 imagery 패턴(6 × 복셀)의 분산 중 encoder 부분공간 U_k가 설명하는 비율. 같은 k의 무작위 부분공간 분포(500회)와 PCA 부분공간, 그리고 같은 방식의 perception 보류 이미지 패턴 값과 비교.
4. **정보 유지:** imagery run 1 대 run 2 target 식별을 encoder z(k차원), 무작위 k차원 투영(평균), PCA k차원, 전체 복셀에서 각각 계산하고 차이를 본다(z − 전체, z − 무작위, z − PCA). viewing에서도 같은 값을 낸다.
5. 모든 식별 정확도는 세트별 후보 6개, 양방향 평균, target 라벨 순열 1,000회로 우연 대비 p를 구한다.

## 판정 (표본이 8단위로 작으므로 구간은 단위 수준의 부트스트랩으로, 판정은 규칙으로만)
- **전제:** (1) viewing 식별이 전체 복셀에서 우연 위(순열 p < 0.05, 8단위 평균), (2) imagery 식별이 전체 복셀에서 우연 위(순열 p < 0.05, 8단위 평균). 하나라도 실패하면 「이 복셀 집합에서는 imagery 신호가 약해 검증 불가」.
- **「가능성 있음」:** 전제 충족 + 정렬 비율이 무작위 분포의 95번째 백분위를 넘는 단위가 8개 중 6개 이상 + (z − 무작위) 식별 차이의 평균이 0보다 크고 8단위 중 6개 이상에서 0 이상.
- **「가능성 낮음」:** 전제 충족 + (정렬 비율이 기준을 넘는 단위가 4개 이하이거나 (z − 무작위)의 평균이 0 이하).
- 그 외는 「판단 불가」. 어느 경우든 perception 대비 imagery에서 정렬 비율이 떨어지는 정도를 사실대로 보고한다.
- 이 점검은 복원 성능 향상의 증거가 아니다. 「imagery가 압축 부분공간에 있다」는 말은 정렬과 정보 유지의 통과 여부만으로 쓰고, 최종 평가(세트 B, 복원)는 별도 기준을 먼저 적은 뒤에 한다.

## 한계 (사전)
세트당 target이 6개라 식별 정확도의 단위가 거칠고 통계 힘이 약하다(우연 1/6). 세트 A(도형)·C(단어)는 자연 장면(세트 B)과 성격이 달라 결과가 자연 장면으로 일반화된다는 보장이 없다. imagery 반응의 SNR이 낮을 수 있다(전제 2). encoder 방향 안정성은 이번에 보지 않는다. 지각 데이터와 imagery 데이터의 스캔 세션 차이로 생기는 평균·분산 차이를 복셀 z-score로만 보정했다.
