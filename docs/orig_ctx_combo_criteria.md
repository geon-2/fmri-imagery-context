# 원본 캡션 + 맥락 라벨을 함께 쓴 타깃 대 원본 캡션 단독 — 판정 기준 (실행 전에 기록, 2026-10-15)

사용자 요청(2026-10-15): 맥락과 원본 캡션을 같이 썼을 때의 예측 성능을 원본 캡션과 비교한다. `docs/stage_structure.md`의 A 단계(타깃을 다루는 방식)에 속한다. 숫자 기준은 제안이며 결과를 본 뒤 바꾸지 않는다. 탐색 단계.

## 고정하는 것
피험자 1·2·5·7, CLIP ViT-L/14 텍스트, 전처리 a(피험자마다 따로), 전체 복셀(압축 없음), 같은 ridge decoding과 평가(보류 폴드 약 1,000장 중 1장 찾기, top-1 주·top-5 함께, 동점 부분 점수), 5겹(같은 폴드). 학습용 이미지는 맥락 조합 비교와 같다(4,999 / 4,956 / 4,955 / 4,967장).

## 타깃
- 기준: 원본 캡션 P1(orig_P1), 맥락 라벨 P1(ctx_P1), 사물 이름 P1(obj_P1).
- **결합(주): orig_P1과 ctx_P1을 이어 붙인 벡터**(각각 L2 정규화된 임베딩 768 + 768). 1단계의 「사물+맥락」과 같은 방식. 하나의 타깃으로 한 번에 예측하고 이어 붙인 전체 공간에서 찾기를 평가한다.
- 결합(보조): 두 임베딩의 평균을 다시 L2 정규화한 768차원 벡터.

## 판정 (이미지 단위 부트스트랩 1,000회 쌍 비교; 구간이 0 제외 + top-1 ≥ 0.02, top-5 ≥ 0.03이면 높음/낮음, 아니면 동등)
1. 결합(주) − 원본 캡션 단독, 결합(주) − 맥락 단독을 피험자별로 판정한다. 「높다/낮다」는 4명 중 3명 이상에서 같은 방향일 때만 쓴다.
2. 결합(보조, 평균) − 원본 캡션 단독도 같은 방식.
3. 셔플 대조(결합 타깃의 행을 이미지 사이에서 섞음): 피험자별 top-1 ≤ 0.005. 넘으면 그 피험자 결과를 쓰지 않는다.
4. 결합이 원본 캡션보다 높지 않으면 「이 설정에서는 맥락을 원본 캡션에 더해도 원본 캡션 단독보다 높지 않다」고 쓴다.

## 한계 (사전)
이어 붙인 타깃은 차원이 두 배이고 두 부분의 구분력이 달라 결합 점수가 두 단독 점수 사이에 놓일 수 있다. 이 비교는 구분 정보량의 차이와 맥락 정보의 가치를 구분하지 못한다. 압축 없는 환경, 지각 decoding이다.
