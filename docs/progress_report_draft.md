## 1. 연구 개요

이 연구는 머릿속으로 떠올린 장면(mental imagery)을 fMRI로 읽어 내는 문제를 다룹니다. 최근 decoder들은 눈으로 본 장면은 꽤 잘 복원하지만, 떠올린 장면에서는 성능이 크게 떨어지고 모델마다 차이도 큽니다. 떠올린 장면은 신호가 약하고 담긴 정보도 적은데, 기존 decoder는 CLIP embedding 같은 큰 표현 전체를 맞혀야 하기 때문이라고 생각했습니다.

그래서 표현 전체를 맞히는 대신, 본 장면의 fMRI와 함께 변하는 적은 수의 '맥락 축'만 찾고, 이 축으로 떠올린 장면을 읽어 보려고 합니다. 새로운 embedding 공간은 만들지 않습니다. 기존 문장 embedding 공간(CLIP 텍스트 인코더)에서 축을 고르되, 텍스트가 아니라 뇌 반응을 기준으로 고른다는 점이 다릅니다.

| 질문 | 내용 | 성격 |
|---|---|---|
| RQ1 | 사물 정보를 넘어, 본 장면의 fMRI와 맥락 embedding이 함께 가진 저차원 축이 있는가 | 사전 확인 |
| RQ2 | 뇌를 기준으로 고른 k개 축이, 뇌와 무관하게 고른 같은 개수의 축(PCA)보다 떠올린 장면을 더 잘 맞히는가 | 주 가설 |
| RQ3 | 기억과 관련된 뇌 영역을 함께 쓰면 더 좋아지는가 | 추가 실험 |

학습에는 NSD(본 장면)를, 평가에는 NSD-Imagery(떠올린 장면)를 씁니다. NSD 이미지는 COCO 이미지라서 COCO의 사람 주석(캡션, 사물 등)을 그대로 쓸 수 있습니다.

## 3. 진행 내용

### 3.1 연구 방향 점검

**맥락의 정의**

맥락은 사물의 조합에 해석적인 의미 정보가 더해진 것입니다. 선행연구(Doerig 등)도 장면 서술을 어떤 사물이 있는지, 서로 어떤 관계인지, 장면의 의미가 무엇인지까지 담은 것으로 보았고, 이런 서술(캡션)의 embedding이 사물 범주 라벨보다 NSD의 뇌 활동을 더 잘 설명한다고 보고했습니다.

**이렇게 정의한 이유**

이 주제를 정하기 전에는 사물 사이의 관계(relation)를 분석하려 했습니다. 관계는 사물 종류에 강하게 얽혀 있어서(wearing, riding 등) 사물을 빼고 순수한 관계만 얻을 수는 없었고, 선행연구(Bogdan 등)도 자신들이 만든 관계 공간이 순수한 관계가 아니라 여러 단서가 섞인 공간이라고 밝히고 있습니다. 다만 사물과 위치 정보를 더해도 설명되지 않는 부분은 남아 있었습니다. 선행연구와 차별성이 부족해 그 주제는 보류했지만, 이 판단을 이어받아 맥락도 사물과 떼어 내서 다루지 않기로 했습니다.

**그래서 달라진 것**

- 라벨은 사물과 이어진 해석까지 포함해서 만듭니다. 사물 이름과 관계 표현만 라벨 값으로 쓰지 않습니다.
- 사물에 기대는 부분과 그렇지 않은 부분은 라벨을 만드는 단계에서 나누지 않고, embedding을 만든 뒤 분석 단계에서 나눕니다(4절).
- 라벨 항목: 암묵적 사건과 기타를 추가했고, 암묵적 사건은 세 갈래(직전·의도·다음)로 나눔
- 외부 자료: COCO-Stuff, Places365 등을 라벨 대체·검증 후보로 추가 (확정 아님)
- 진행 방식: 라벨링 계산 비용이 커서, 먼저 적은 양으로 시험한 뒤 넓히기로 함

**9/17 미팅에서 나온 우려**

본 장면으로 학습한 decoder를 더 약한 imagery 신호에 적용하기 어렵다는 지적이 있었습니다. 이는 라벨을 만드는 일과는 별개의 문제로 구분했습니다. 본 장면 안에서 decoder가 안정적으로 학습되는지 먼저 확인한 뒤 imagery에 적용합니다. 어느 정도 성능이면 imagery로 넘어갈지의 기준은 아직 정하지 않았습니다.

### 3.3 맥락 라벨을 만드는 방법

같은 장면도 사람마다 다르게 표현하므로, 라벨을 붙일 때는 해석을 하나로 정하지 않고 여러 개를 남기기로 했습니다.

- 한 항목에 라벨이 여러 개 있어도 됩니다. 비슷한 표현을 억지로 하나로 합치지 않습니다.
- 원칙적으로 같은 이미지를 3번 따로 라벨링하고, 각 라벨이 몇 번 나왔는지 기록합니다. 이번에는 이미지당 1회만 했습니다. 라벨은 지우지 않습니다.
- 사물 이름과 관계 표현(위에, 옆에 등)은 라벨로 쓰지 않습니다.

| 항목 | 담는 내용 |
|---|---|
| 장소 종류 | 장소의 종류 |
| 환경 | 실내·실외, 조명, 날씨, 붐비는 정도 등 |
| 활동 | 지금 화면에 보이는 동작, 또는 그 공간의 사용 방식 |
| 암묵적 사건 | 화면 밖의 이야기: 직전의 일, 지금 행동의 의도, 다음에 일어날 일 |
| 공간 규모 | 공간의 크기와 구도 |
| 기타 | 위 항목에 들어가지 않는 보충 내용 (대부분 비어 있음) |

### 3.4 라벨링 과정

라벨링은 작은 규모에서 시작해 단계적으로 넓혔습니다. 확대하는 중에도 문제가 발견되어 프롬프트를 여러 번 고쳤고, 그래서 코어 1,000장은 v9, 나머지는 v10입니다. 아래 네 단계는 대체로 시간순이며, 직접 라벨링은 파일럿과 일부 겹쳐 진행했습니다.

| 단계 | 규모 | 한 일 | 얻은 것 |
|---|---|---|---|
| 1. 파일럿 | 300장 | Claude로 라벨링을 끝까지 돌려 봄 | 캡션 기반은 사물 위주라 조명·공간감 같은 맥락이 빠짐 → 이미지를 직접 보는 방식으로 변경 (v3). 장소 종류 표현 853가지로 분산 |
| 2. 직접 라벨링 | 200장 | 파일럿 이미지를 직접 보고 라벨링 | 사람은 직전·의도·다음 일까지 떠올림 → '암묵적 사건' 항목 추가 (v4), 공간 규모·구도 항목 확인. 이미지에 없는 세부 내용을 지어내거나 하나로 단정하는 문제 → 근거가 있을 때만 쓰고, 구분이 안 되면 그 애매함 자체를 라벨로 기록 |
| 3. 프롬프트 수정 | 코어 1,000장 | 파일럿을 1,000장으로 넓히며 프롬프트 수정 (v7~v9) | 문장 복사 (야구장 사진의 문장이 화장실 사진 49장에 들어감) → 복사 금지 (v8). 이미지를 보지 않고 끝냄 (파일 50개를 1초 만에 생성) → 배치마다 새 작업 실행, 이미지 열람 자동 검사. 한국어 출력 → 영어 지정 (v9) |
| 4. 라벨링 자동화 | 11,150장 | 배치마다 새 작업을 실행하고 자동 검사 | 라벨 수 부족 (이미지당 7.8개) → 항목별 최소 개수 지정 (v10). 검사기 오류로 12시간 정지 → 오류 수정 후 재개 |

파일럿 라벨은 항목 구성이 지금과 달라서 분석에는 쓰지 않고, 기준을 정하는 과정의 근거로만 남깁니다.

### 3.5 3~4단계 상세

코어 1,000장과 새 이미지를 자동으로 라벨링해야 해서, 방법을 여러 번 고쳤습니다.

**시도와 문제**

| 시도 | 방식 | 문제 | 조치 |
|---|---|---|---|
| 1차 | 20장씩 묶어 50번을 이어서 한 번에 실행 | 앞 이미지의 문장이 관련 없는 이미지에 그대로 복사 (야구장 사진의 문장이 화장실 사진 49장에 들어감) | 결과 전체 폐기 |
| 2차 | 같은 방식에 '복사하지 말 것' 규칙 추가 | 이미지를 열어 보지 않고 종료. 파일 50개를 1초 만에 만든 작업, 앞 60장만 제대로 하고 나머지 940장은 캡션을 정해진 틀에 끼워 넣은 작업 등 | 결과 전체 폐기 |
| 지금 방식 | 배치마다 새 작업을 따로 실행, 끝날 때마다 자동 검사 | 아래 참고 | 사용 중 |

**지금 방식**

1. 이미지를 50장씩 묶고, 배치마다 앞선 내용을 전혀 모르는 새 작업을 따로 실행합니다. 그래서 앞 배치의 내용이 다음 배치에 섞이지 않습니다.
2. 배치가 끝날 때마다 자동으로 검사합니다.
3. 통과한 이미지는 바로 저장하고, 통과하지 못한 이미지만 다시 합니다. 통과하지 못한 결과도 지우지 않고 보관하며, 어떤 모델과 프롬프트로 만들었는지 매번 기록합니다.
4. 이미지 순서를 무작위로 정해 두었습니다. 중간에 멈추더라도 그때까지 처리한 이미지는 전체에서 무작위로 뽑은 표본이 됩니다.

**자동 검사 항목**

| 검사 | 확인하는 것 | 처리 |
|---|---|---|
| 이미지 열람 | 작업 기록에 그 이미지 파일을 열어 본 기록이 있는지 (가장 중요) | 재시도 |
| 형식 | 모든 항목의 존재, 값 형태의 적합성 | 재시도 |
| 문장 복사 | 같은 문장이 관련 없는 이미지에 붙었는지 | 재시도 |
| 캡션 재조합 | 캡션 단어를 재배열만 했는지 | 재시도 |
| 언어 | 라벨의 영어 여부 | 재시도 |
| 항목별 최소 개수 | 장소 종류 2개, 환경 3개, 활동 2개 이상인지 | 재시도 (세 번째 시도는 표시만) |
| 반복 문장, 처리 시간 | 여러 이미지에 되풀이되는 문장, 비정상적으로 짧은 처리 시간 | 표시만 |

**검사 방법 시험** (문제가 있었던 1차 시도의 데이터로 확인)

| 방법 | 결과 |
|---|---|
| 배치 안 중복 문장 검사 | 오염된 49장 중 17장 검출 |
| 전체 이미지 기준 반복 문장 검사 | 49장 모두 검출, 문제없는 이미지도 9~16% 함께 검출 → 재시도 대신 표시만 하기로 결정 |
| 이미지 열람 기록 검사 | 정상 작업 20장 모두 통과, 5장만 열어 본 작업은 20장짜리 기준으로 검사하면 15장 검출 |

**모델 선택.** 같은 이미지 5장으로 여러 설정을 비교했습니다. 어느 모델이든 캡션을 베끼지 않고 이미지에서 뽑은 표현이 대부분이었고, 품질 차이는 크지 않았습니다.

| 모델 | 이미지당 라벨 수 | 사용량의 특징 |
|---|---|---|
| Claude Sonnet 5.5 | 17~18개 | 이미지 수에 비례해 사용량 계속 증가 |
| GPT-5.5 | 15~16개 | 시작 시 고정 비용이 대부분이라 많이 묶을수록 유리 |
| GPT-5.6 (Terra, Sol) | 11~13개 | 라벨 수가 적음 |

대량 라벨링은 GPT-5.5(Codex)로 하기로 했습니다.

**라벨 수 문제.** 코어 1,000장을 처리해 보니 이미지 한 장당 라벨이 평균 7.8개로 적었습니다. 같은 모델에서 한 번에 처리하는 이미지 수가 많을수록 라벨이 줄었습니다.

| 한 번에 처리한 이미지 수 | 5장 | 20장 | 40장 | 50장 |
|---|---|---|---|---|
| 이미지당 라벨 수 | 16.4 | 11.8 | 8.6 | 7.8 |

그래서 프롬프트(모델에게 주는 지시문)에 항목별 최소 개수(장소 종류 2개, 환경 3개, 활동 2개 이상)와 '이미지가 몇 장이든 한 장당 분량은 같다'는 내용을 넣었습니다.

| 같은 100장 기준 | 이전 프롬프트 | 새 프롬프트 |
|---|---|---|
| 이미지당 라벨 수 | 8.6 | 10.8 |
| 세 항목의 최소 개수를 모두 채운 이미지 | 18% | 100% |

**현재까지의 결과** (10월 1일 기준)

| 항목 | 값 |
|---|---|
| 라벨링한 이미지 | 11,150장 (코어 1,000장은 v9, 나머지 10,150장은 v10) |
| 처음 검사에서 통과한 비율 | 99.99% (1만 장 시점 기준) |
| 이미지당 라벨 | v10 평균 10.2개 (10,150장 기준: 장소 종류 2.0, 환경 3.4, 활동 2.0, 암묵적 사건 1.1, 공간 규모 1.5, 기타 0.2), v9 평균 7.8개 |
| 라벨링 횟수 | 이미지당 1회 |

### 3.6 라벨 분포 확인

라벨의 분포에 구조적인 이상(한 값으로의 쏠림, 같은 문장의 복사, 최소 개수만 겨우 채운 경우)이 있는지 확인했습니다. 이 확인은 라벨이 이미지에 맞는지를 보여 주지 않습니다. 라벨의 품질은 일부를 직접 확인하는 방식으로 따로 봅니다(4절). 분포 확인에는 통과 기준을 두지 않았습니다.

**이미지당 라벨 수**

![그림 1. 항목별 이미지당 라벨 수 분포 (위: 코어 v9, 아래: 그 밖 v10)](docs/report_figures/label_count_hist.png)

- v10은 환경 3~4개, 장소 종류와 활동은 대부분 2개입니다. 최소 개수는 지켜졌고, 대부분 하한에 맞춰 쓴 셈입니다.
- 코어(v9)는 활동의 80%가 1개입니다. 최소 개수 규칙이 생기기 전이라서입니다.

**라벨 값의 의미 분포**

라벨 값을 문장 embedding(all-mpnet-base-v2)으로 바꿔 100개 군집으로 묶어 보았습니다.

![그림 2. 라벨 값의 의미 지도. 항목마다 값 6,000개를 표본으로 60개 군집으로 묶고, 가장 큰 8개 군집에 번호를 붙였습니다 (시각화용 2차원 지도)](docs/report_figures/label_cluster_map.png)

- 가장 큰 군집도 전체 라벨의 2.3~4.3%(고유 값 전체를 100개 군집으로 묶은 경우)였습니다. 라벨이 몇몇 의미에 몰려 있지는 않다는 뜻이고, 라벨이 맞다는 뜻은 아닙니다. 군집 방법이 크기를 비슷하게 만드는 경향도 있어서, 균등한 정도는 근거로 쓰지 않습니다.
- 군집은 야구장, 테니스장, 주방, 욕실, 스키장처럼 알아볼 수 있는 장면 유형이었습니다(그림 2). 맥락 라벨이 사물이나 종목과 가깝다는 뜻이기도 합니다.
- 공간 규모 항목은 크기와 구도에 장면 종류(음식, 스포츠, 거리, 동물)가 섞여 있습니다. 공간 배치를 따로 분리할지는 이후에 판단합니다.
- 기타 항목은 워터마크, 흑백 처리, 정사각형 필터처럼 사진 자체의 특징이 모였습니다. 의도한 대로입니다.

**한 이미지 안의 라벨**

3.3절에서 같은 장면에 대한 해석을 하나로 정하지 않고 여러 개 남기기로 했습니다. 이 방식이 실제로 서로 다른 해석으로 나타났는지, 같은 말을 반복해서 개수만 채운 것은 아닌지 보려고 했습니다. 같은 이미지에 붙은 같은 항목의 라벨 쌍마다 두 라벨의 문장 embedding 유사도를 계산하고, 전체 라벨에서 무작위로 뽑은 라벨 쌍의 유사도와 비교했습니다.

![그림 3. 같은 이미지에 붙은 라벨 쌍의 유사도 (임의의 라벨 쌍과 비교)](docs/report_figures/within_image_similarity.png)

- 같은 이미지의 라벨 쌍은 임의의 쌍보다 비슷하면서도 같은 말을 바꿔 쓴 수준(유사도 0.8 이상)은 거의 없었습니다. 장소 종류는 평균 0.52(임의 쌍 0.22), 활동은 0.42(0.10)입니다. 같은 말을 반복해서 개수만 채운 것은 아니라는 뜻입니다. 다만 이것은 모델 한 개가 낸 여러 해석입니다. 사람들 사이의 해석 차이를 얼마나 담았는지, 그 해석이 이미지에 맞는지는 이 그림으로 알 수 없습니다.
- 환경과 공간 규모는 임의 쌍보다 조금만 높습니다. 조명, 실내외, 붐비는 정도처럼 서로 다른 측면을 적기 때문입니다.

## 4. 앞으로의 계획

**라벨링**

- 사용량이 다시 채워지면 라벨링을 더 진행합니다. 먼저 평가에 쓸 이미지(shared1000 1,000장)에 같은 방식으로 라벨을 붙이고, 같은 이미지를 한 번 더 라벨링해 결과가 얼마나 비슷한지(재현성)도 확인합니다.
- 필요하면 코어 1,000장(v9)을 v10으로 다시 라벨링해 버전을 맞추는 것도 검토합니다.
- 라벨링 모델이 하나뿐이고 이미지당 1회라는 한계는 위의 재현성 확인으로 보완하고, 필요하면 다른 모델로 일부를 라벨링해 비교합니다. 캡션은 COCO 원본이라 검증하지 않았고, 학습에 쓰게 될 때 다시 판단합니다.

**라벨 확인**

- 11,150장 중 100장을 직접 확인합니다. 라벨마다 맞음, 애매, 틀림으로 판정하고, 틀림 비율이 10% 이하면 통과, 20%를 넘으면 해당 항목의 재라벨링을 검토합니다(암묵적 사건은 기준을 한 단계 완화). 기준은 확인하기 전에 정해 두었습니다.
- 기준을 엄격하게 잡지 않은 것은, 맥락 라벨이 사람마다 해석이 갈리는 정보이고 수천 장 단위로 집계되어 쓰이기 때문에 무작위 오류의 영향이 작다고 보았기 때문입니다. 오류가 한쪽으로 쏠렸을 가능성은 재현성 확인으로 따로 봅니다.
- 표본을 만들기 전에 30장을 기준 없이 훑어보았을 때는 이미지에 맞는 라벨이 대부분이었지만, 정성적인 인상이라 검증 결과로는 쓰지 않습니다.

**분석**

- 원본 캡션, 사물 이름만, 맥락 라벨 세 가지 텍스트를 같은 모델(CLIP 텍스트 인코더)로 embedding으로 만듭니다. 다른 embedding 모델과 비교해 이 선택을 다시 확인합니다.
- embedding과 뇌 반응이 정보를 함께 가지고 있는지 먼저 확인하고(RQ1), 뇌 반응의 설명력을 세 텍스트로 나누어 맥락 라벨에만 있는 고유한 설명력을 봅니다.
- 함께 변하는 축 k개를 찾아 decoder를 학습하고 NSD-Imagery에 적용합니다(RQ2). 뇌와 무관하게 고른 축(PCA)과 CLIP-image 목표 등과 비교합니다. NSD-Imagery의 자연 장면이 5장뿐이라 효과 크기와 신뢰구간으로 보고하고 주장 범위를 제한합니다.
- 기억 영역을 더한 실험(RQ3), 통계 검정, 시각화, 최종 보고서로 마무리합니다.
- fMRI는 피험자 1의 준비를 마쳤고, 나머지 피험자와 NSD-Imagery 데이터를 받아 둡니다.
