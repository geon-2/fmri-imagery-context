# 병목 encoder → z → decoder 가능성 점검 2(decoder 포함, 학습은 perception만) — 판정 기준 (실행 전에 기록, 2026-10-14)

사용자 정리(2026-10-14): imagery는 평가로만 쓴다. 압축(encoder)이 imagery와 매칭된다고 가정하고, 압축 후 decoder가 이미지(임베딩)를 복원하는 과제를 perception 데이터만으로 학습한다. imagery를 같은 encoder → decoder에 통과시켰을 때 성능이 유지되는지 본다. 앞선 점검(`docs/bottleneck_feasibility_criteria.md`)은 encoder 부분공간 쪽만 보고 decoder 단계가 없었으므로 이것으로 보완한다. 본 연구 결과를 내기 전의 **가능성 점검**이다. 세트 B(자연 장면)는 열지 않는다. 숫자 기준은 제안이며 결과를 본 뒤 바꾸지 않는다. 탐색 단계.

## 구조 (모든 학습은 perception, 피험자마다 따로)
- 입력: 전처리 a로 고른 복셀(표준화). 학습 이미지의 80%로 학습, 20%(약 1,000장)는 perception 평가용 보류.
- encoder(지도형 병목): 복셀 → 타깃 임베딩 ridge(λ = 1e4) 적합값의 상위 k개 방향으로 만든 복셀 공간의 k개 방향 U_k. z = 복셀 · U_k.
- decoder: z(k차원)에서 타깃 임베딩(표준화 공간 전체)으로 가는 선형 회귀(최소제곱). perception 학습 이미지로만 학습.
- 타깃 종류: CLIP 이미지 임베딩, 맥락 라벨 P1(ctx_P1), 원본 캡션 P1(orig_P1).
- k: 16, 32, 64, 128 모두 보고. **주 k = 64**(B 단계에서 k=32는 perception에서 압축 없음보다 낮았고 k가 커질수록 따라잡는 경향이 있어, 결과를 보기 전에 고정).
- 비교: 풀 릿지(병목 없음, 같은 λ), 같은 k의 무작위 투영(5회 평균) + 같은 decoder, 복셀 PCA k + 같은 decoder.

## 평가
1. **perception 유지:** 보류 20%에서 복원 임베딩으로 이미지 1장 찾기(top-1·top-5, 동점 부분 점수, B와 같은 평가). 「유지」 = 병목의 top-1이 풀 릿지보다 0.02 이상 낮지 않음.
2. **imagery(세트 A·C, 평가 전용):** 세트마다 target 6개. imagery 2 run 평균 패턴을 같은 encoder → decoder에 통과시켜 임베딩을 복원하고, 후보 6개의 임베딩과 비교해 1개 찾기(우연 1/6, 양방향 평균, 후보 임베딩은 같은 표준화로 변환).
   - 세트 A(도형 6개): 후보 = target 이미지의 CLIP 이미지 임베딩, decoder 타깃 = CLIP 이미지 임베딩.
   - 세트 C(단어 6개: stripes, zebra, mammal, yellow, banana, fruit): 후보 = 단어의 CLIP 텍스트 임베딩, decoder 타깃 = ctx_P1(주), orig_P1(보조).
   - 단위: 피험자 4명 × 세트 2개 = 8단위. imagery 베타는 복셀마다 해당 피험자의 imagery 실험 전체 시행에서 z-score.
3. **양성 대조(대응 확인):** 같은 파이프라인으로 viewing run(같은 세트의 target을 실제로 본 run)을 풀 릿지로 복원해 후보 6개 중 찾기. 이것이 우연보다 높아야 target 대응(열 순서)이 맞다고 본다.
4. 우연 대비 검정: 후보 순서를 단위 안에서 섞는 순열 1,000회, 8단위 평균으로 p.

## 판정
- **전제:** (1) viewing 복원 식별(풀 릿지)이 우연 위(p < 0.05), (2) imagery 복원 식별(풀 릿지)이 우연 위(p < 0.05). 하나라도 실패하면 「검증 불가」.
- **「가능성 있음」:** 전제 충족 + perception 유지(주 k=64에서 세 타깃 모두 또는 주 타깃 CLIP 이미지·ctx_P1에서) + (병목 − 무작위 k) imagery 식별 차이의 평균이 0보다 크고 8단위 중 6개 이상에서 0 이상.
- **「가능성 낮음」:** 전제 충족 + ((병목 − 무작위 k) 평균이 0 이하이거나 0 이상인 단위가 4개 미만).
- 그 외는 「판단 불가」. perception 유지가 실패하면 imagery 결과와 별개로 그 사실을 적는다.
- 이 점검은 복원 성능 향상의 증거가 아니며 세트 B 평가를 대신하지 않는다.

## 한계 (사전)
target이 세트당 6개(우연 1/6)라 통계 힘이 약하다. 세트 A(단순 도형)와 C(단어)는 COCO 자연 장면과 달라 일반화를 장담할 수 없다. 단어의 CLIP 텍스트 임베딩을 정답으로 쓰는 것은 근사(ctx_P1은 맥락 라벨 평균)이다. imagery 열 순서와 target 대응은 viewing 양성 대조로만 확인한다. 단위가 8개로 작아 판정은 규칙으로만 한다.
